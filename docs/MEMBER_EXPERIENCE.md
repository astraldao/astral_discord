# 普段の操作を整える（v6.14）

予定表・日程調整・卓とPC・ゲーム・画像工房・自分の読み方まで、既存の画面をまとめて整備しました。状態と次の操作を先に出し、詳しい内容は項目を分けて確認できます。

| 機能 | 改善した点 |
| --- | --- |
| 予定の詳細 | 日時・翌日の表記・日本時間を先に表示し、場所・予定表名・説明を別項目へ。説明は省略しません。 |
| 日程調整 | 候補日程・説明・回答の選択肢・パスワード設定の有無を分けて表示。入力修正と共有結果の未確認は注意色で案内。 |
| 卓・キャラシの入口 | 進行中/完了した卓、ベース卓、パネル/PCの登録数を表示。関連操作は選択欄へ集約。 |
| 卓セット | シナリオ・伝助・参加PCを別項目に表示。PCの一覧は8件ずつで全文を確認可能。 |
| PC一覧 | 登録とページ移動をボタン、検索・更新・絞り込み・ZIP保存を選択欄へ。一般向けにはメニューへの戻り先を追加。 |
| 4目並べ | 7つの列ボタンを1つの選択欄に変更。満杯の列は除き、置ける列ごとの空きマス数を表示。 |
| チップゲーム | 選択中の掛け枚数が残高を超えていたら、残高以内の枚数を選び直す案内を表示。掛け枚数は自動変更しません。 |
| 画像工房 | 元画像と完成画像の寸法・容量を比較し、容量が増えた場合も正しく表示。 |
| 自分の読み方 | 登録した読み方と実際の告知文を別項目へ。解除確認は先頭・注意色で表示。 |

## 操作の入口

- メンバー用は `/menu`、管理用は `/admin` のままです。
- 卓・キャラシの入口では「ベース卓・キャラシの操作を選ぶ」を使います。
- PC一覧は「検索・表示・控えの操作を選ぶ」から検索・表示範囲・ZIP保存へ進みます。ZIPは従来と同じ権限確認と確認画面を使います。
- 4目並べは「コマを置く列を選ぶ」から左から1〜7列目を選びます。選ぶと1手進みます。途中で戻っても同じチャンネルから再開できます。

PC一覧の古い操作欄は、対象パネル・ページ・検索語・表示範囲が変わっている場合に拒否します。管理権限・本人・元チャンネル・期限・保存前の権限確認は従来どおりです。秘匿PCやTXTの公開範囲は変わりません。

## 確認文と詳細の範囲

日程調整の候補数は空行を除いた入力行の数です。候補の解釈・日程の自動確定は行いません。長文は従来と同じ表示上限で、修正フォームから全文を確認できます。入力値・送信内容・作成前の確認・結果不明時の再作成禁止を維持します。

卓セットは参加PCを先頭3件まで表示し、残りは「確認・編集・その他の操作 → 参加PCを確認・外す」で全件を開けます。8件ごとの一覧は登録やTXTを消さずに確認するための画面です。

4目並べのルール・Botの思考・盤画像・無料の条件、チップの抽選・精算、画像変換の制限・本人だけの添付・処理終了時の破棄は変更していません。新しい依存・ENV・保存形式・コマンドはありません。
