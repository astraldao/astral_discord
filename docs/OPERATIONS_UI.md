# 運用画面を見やすく（v6.13）

結果と次の操作を先に出し、長い説明や内訳は選択欄から開く形にしました。すべて既存の `/admin` にまとまっています。

## 脆弱性診断

最初に勧告の件数・確認日時・対象数を表示し、1ページ3件を項目ごとに確認できます。画面は選択欄・診断/ページ移動・戻り先の3行です。

「対象・詳細・保存を選ぶ」に次をまとめました。

- 結果の一覧、すべて・実行用・開発用の絞り込み
- 表示中の勧告の「詳しく」
- 対象・OSVへの送信内容・注意点
- 全件JSONの保存

「詳しく」では、取得済みの全対象パッケージと修正版候補を5項目ずつ確認できます。後半の対象や複数の修正系列も画面から辿れます。選択した絞り込みを維持し、「結果の一覧」で元のページに戻ります。全件JSONは絞り込み前の結果を保存します。

切り替えだけではOSVへ再照会せず、更新や修正も実行しません。安全性の保証ではないことは結果にも表示し、詳しい対象外・キャッシュの説明は「対象・送信内容・注意点」から確認できます。未確認や照会失敗を、問題なしに置き換えません。

古い選択欄を再利用して違う勧告を開かないよう、表示の世代も確認します。本人・元チャンネル・現在の管理者権限・有効期限の確認を維持しています。[診断の範囲](SECURITY_SCAN.md)。

## バージョン管理

既存の確認・更新ボタンに、表示を切り替える選択欄を追加しました。

| 表示 | 内容 |
| --- | --- |
| 概要 | 現在版と確認した最新版、取得量・追加の保存容量・OSの空きの要約 |
| 容量の内訳 | コード圧縮ファイル、依存の再利用/新規取得、保存データの控え、小計、追加領域と契約上限の注意 |
| 更新の流れ・注意点 | 確認・明示更新・再接続の手順、進行中の操作、dnd、旧版の保持 |

「変更内容を見る」はカード内のリンクになり、ボタンは1行最大2つです。表示を変えても通信・容量の再計測・更新開始は行いません。更新を確定する前に内訳を読んでも、確認した対象コミットは維持します。

同じ現在版・対象版の有効な見積もりで、OSの空きが最低条件200 MiBを下回っているときは、確認が必要なことを先頭・注意色で示します。古い版の値・未確認の値からは判定しません。表示は確認時点の目安であり、更新処理でも空き容量を再確認します。[容量の測り方と制限](UPDATE_CAPACITY.md)。

## ENV・起動設定

再起動待ちの変更があるかを冒頭に表示し、許可された2項目の「稼働中」と「次回起動」を並べます。読み上げはON/OFF、スレッド数は単位付きで確認できます。変数名も残しています。

保存前に変更内容を確認し、保存後の再起動で反映します。空欄で外部設定・既定値へ戻す仕組み、保存値の優先順位、トークンを表示・編集しない条件は同じです。[再起動と設定](RESTART.md)。


実際の送信データから作ったモックです。架空の勧告・バージョン・容量を使い、実際の脆弱性や更新を示しません。Discord実機の幅・折り返し・フォントの再現や確認とは区別してください。

新しい依存・ENV・コマンド・保存形式はありません。本番への反映は `/admin → バージョン管理` から手動で行います。
