# 脆弱性診断（v4.5）

管理者が、実行中の版のnpm依存パッケージに該当する既知の勧告を確認する機能です。

## 操作

1. `/admin → 運用・管理 → 脆弱性診断` を開く。`/admin` の「操作」や動作診断からも開けます。
2. 画面に表示される対象と送信内容を確認し、「診断を開始」を押す。
3. 確認日時、Botの版、ロックの識別子、対象数、深刻度別の勧告数を確認する。
4. 勧告があればページを切り替え、対象パッケージの版・実行用/開発用・直接/間接・勧告リンク・修正版候補を確認する。
5. 「バージョン管理」から更新内容を確認する。診断をしただけでは更新も修正もされません。

本人だけに表示し、管理者・元のチャンネル・画面の有効期限を確認します。再確認も含め、成功した結果は5分間再利用します。失敗は30秒間再利用し、その後に再診断できます。画面の操作期限は10分です。Botを再起動するとキャッシュは消えます。

## 対象と送信内容

実行中のソースに同梱した `package-lock.json` が対象です。直接・間接・開発用・任意依存を含め、公式npmレジストリ由来の正確なパッケージ名・バージョンを、OSV（`https://api.osv.dev`）へ送信します。重複する同じパッケージ・版は1種類にまとめます。プロジェクト名・ENV・トークン・サーバーID・予定・投稿・音声・ローカルパス・`.npmrc` は送りません。

独自レジストリ、git、ローカルやリンク、privateフラグ付き、形式を確認できない依存は対象外として数えます。公式レジストリ上のスコープ名だけで公開/非公開を判別することはできません。対象の名前と版を外部送信したくない場合は診断を開始しないでください。

実際にインストールしたファイルの改変検査や、OS・Node.js本体・Python・VOICEVOXの診断、Bot独自コードの監査は含みません。ロックにある任意依存がホスト上では未導入のこともあります。対象外がある場合、全依存を確認した結果ではありません。

## 結果の読み方

- 「勧告0件」は照会対象と確認時点の情報に限ります。OSVへの登録前・未公開の脆弱性は分かりません。
- 件数はOSVの勧告ID単位です。1件の勧告が複数のパッケージ・版に該当する場合は、同じ勧告内に表示します。
- 深刻度はOSVの勧告情報です。取得できない・定義されていない場合は「未確認」にします。独自に低危険度とは判定しません。
- 詳細は1回の診断で最大20勧告まで取得します。残りや詳細取得に失敗した勧告も一覧に残し、リンクから確認できます。
- 修正版候補は勧告中の固定バージョン番号です。複数の修正系列があり、表示した候補だけで解決するとは限りません。互換性や適用可否は勧告とBotの更新内容を確認してください。
- 通信失敗・タイムアウト・不完全な応答は「診断できませんでした（未確認）」と表示します。失敗を0件に置き換えません。

通信全体15秒、応答サイズ・パッケージ数・詳細取得数・同時実行を制限しています。上限を超えるロックや応答では診断を完了できません。照会先が混雑している場合は少し待ってから再診断してください。

この機能を使うための依存追加やENV変更は不要です。v4.5へ通常の手動更新を行ってください。[更新手順](../README.md)。
