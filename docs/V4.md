# v4.0 の使い方

予定表の連休・定例登録と、音声診断の履歴を追加しました。コマンドは `/menu` と `/admin` の2つです。

## 連休をひとつの予定にする

管理者が `/admin → 予定表 → 予定を追加` で、日付を `2026/10/30〜2026/11/02`、時刻を空欄にして保存します。最大31日で、月をまたいでも1つの予定です。各日・各月の表示、検索、ICS取り出しにも反映します。

![複数日の終日予定を週ごとの帯で表示する見本。架空の予定です。](previews/calendar-v4.png)

## 定例の予定をまとめて追加する

`/admin → 予定表 → 予定の詳細 → 繰り返して追加` で、毎日・毎週・隔週・毎月と追加件数を選びます。全日程を確認してから、1〜26件をまとめて保存します。

元の予定は保持し、追加した予定も1件ずつ編集できます。毎月31日など該当日がない月は飛ばします。自動通知・自動追加はありません。[詳しい操作](CALENDAR.md)

## 音声診断を比べて取り出す

`/admin → 運用・管理 → 動作診断 → 処理速度を測る → 測定履歴` で、終了済みの直近5件を選べます。完了した測定同士の差と条件の違いを表示し、JSONを本人だけの画面から取得できます。履歴はBot再起動で消えます。

測定方法・固定文・声は維持しています。この更新で読み上げの300ms以内を保証するものではありません。[測定値の見方](DIAGNOSTICS.md)

## 更新と確認

1. `/admin → バージョン管理 → 更新を確認` でv4.0.0とコミットを確認する。
2. 更新内容を確認し、「この版に更新する」を実行する。読み上げ・ゲームなどが進行中の場合は、終了後に実行する。
3. `/admin` を開き直して稼働版を確認し、予定表の追加フォームと音声診断の履歴ボタンを開く。

追加のENV・依存パッケージ・手作業のデータ移行はありません。既存の設定・単日予定・PC・チップ残高は維持します。複数日の予定は任意の終了日を追加する形式で、旧版では期間を表示できません。今回の変更にホスティング側の再導入は不要です。

自動テストは模擬Discord・模擬音声処理を使用します。本番Discordの表示と実際の音声処理は、手動更新後に確認してください。

カレンダー見本は架空の予定を使い、`node scripts/preview-calendar.js` で再生成できます。
