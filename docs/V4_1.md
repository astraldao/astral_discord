# v4.1 の使い方

ICS取り込みと、チャットに合わせた読み上げ操作を追加しました。入口は `/menu` と `/admin` の2つです。

## 別のカレンダーから予定を取り込む

`/admin → 予定表 → 検索・取り出し → ICSファイルから取り込む` で `.ics` を1つ選びます。

新規件数・重複件数・各予定の日時を確認し、選択欄から場所・説明も確認できます。「新規N件を取り込む」を押すまでは保存しません。保存すると、その予定表の既存の共有先にも表示します。

UTF-8・256KiB以内・200予定まで。終日・複数日・UTC・日本時間・翌日終了に対応します。繰り返し規則や取消など未対応の予定があれば全体を拒否します。

予定名・日時・場所・説明が同じ予定は除外します。既存の予定は上書き・削除しません。UIDによる更新・自動同期・通知は行いません。[詳しい対応形式](CALENDAR.md)

## 読み上げをチャット向けにする

`/menu → 読み上げ` の読み方を「チャット向け」にすると、リンク・コード・伏せ字・カスタム絵文字を短い言葉にしてから読みます。変更は新しい投稿だけに適用し、待機中の本文や順番は変えません。

従来の「そのまま」が既定です。停止・再起動で既定へ戻ります。どちらも本文50文字＋「以下略」です。

## 今の文章を読み切り、待機分だけ消す

「待機分を消去」で件数を確認し、30秒以内に「確認時の待機分を消去」を押します。すでに再生へ進んだ文章と、確認後に届いた投稿は残します。接続や音声モデルを準備し直す必要はありません。[読み上げの操作と権限](BACKUP_VOICE.md)

## 更新する

`/admin → バージョン管理 → 更新を確認` でv4.1.0を確認し、内容を見て手動更新してください。今回の更新に新しいENV・依存パッケージ・手作業のデータ移行・ホスティング側の再導入は不要です。

設定・キャラシは、ファイル保存中に操作権限が失効した場合も変更を確定しないよう強化しました。既存の予定・設定・PC・チップ残高を保持します。

検証は模擬Discord・模擬音声処理と一時ファイルで行っています。本番の画面・読み上げは手動更新後に確認してください。この更新で300ms以内の読み上げを保証するものではありません。
