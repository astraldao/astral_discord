# v5.5 操作画面の整理

Discordでは端末別のボタン配置やCSSを指定できません。同じネイティブの操作画面をPCとスマホで使い、今回整理した主要画面は1行3ボタン以内・全体5行以内に収めています。文字サイズや実際の折り返しはDiscordの表示設定によります。

よく使う操作と前後移動をボタンに残し、補助操作は説明付きの選択欄へまとめました。選択欄にはその画面・権限で使える操作だけを表示します。削除や待機分消去は確認画面へ進み、そこで確定します。

| 画面 | 主なボタン | 選択欄へまとめた操作 |
|---|---|---|
| メインメニュー | VCに入る・予定表・使い方 | 読み上げ・ゲーム・個人設定など6機能 |
| 管理ホーム | 予定表または初期設定・バージョン管理 | 全15機能、カテゴリからの絞り込み |
| 管理カテゴリ | 管理メニューへ | カテゴリ内の設定・管理機能 |
| 予定の一覧 | 前の月・今月・次の月、ページ移動 | 追加・検索・日付・検索整理の入口 |
| 予定の詳細 | 編集・一覧へ戻る・前後移動 | 複製・繰り返し・ICS保存・履歴・削除確認 |
| 予定表の検索整理 | 予定を検索・一覧へ戻る | ICS保存・取り込み・共有・整理・名前変更 |
| 卓セットの詳細 | シナリオ・参加PC・固定/進行状態 | PC確認・編集・複製・削除確認 |
| 読み上げ | 一時停止/再開・停止 | 状態更新・内訳・待機分の消去確認 |
| 動作診断 | 更新・速度測定 | 概要・音声・ダイス/Jev・VC/権限・実行環境、対処と関連診断 |
| ゲーム選択 | 続きに戻る・メニューへ | 遊ぶゲーム、チップの残高・譲渡 |
| チップゲーム | 予想・開始・勝負の操作 | 10/50/100枚のうち、残高で使える枚数 |

## 予定表

一覧の **「追加・検索・その他の操作」**（閲覧用は **「検索・日付・その他の操作」**）から操作を選びます。月・週の移動とページ移動は別の行です。追加や検索を選ぶと入力フォームを開きます。

詳細では **「予定の操作を選ぶ」** からICS保存・複製・履歴などを選びます。色は専用の選択欄です。閲覧用の画面に編集・削除を出さず、値を書き換えても編集できません。検索・整理画面では **「保存・管理の操作を選ぶ」** から取り込みや共有へ進みます。詳しくは [予定表](CALENDAR.md) を参照してください。

## 卓セット・その他の管理画面

卓セットの **「確認・編集・その他の操作」** から参加PCの確認、卓名・伝助の編集、複製、削除確認を選びます。削除の確定や固定・進行状態は明示的なボタンを使います。卓が変更された場合は古い選択欄を拒否し、開き直して確認できます。バナーと起動設定では上位画面への重複リンクを減らしました。

## 読み上げ

**「状態・内訳・待機分の操作」** から **「状態を更新・操作画面へ」** または **「処理状況・内訳」** を選びます。待機分があるときだけ **「待機分を消去…」** を表示します。現在の音声と確認後の新しい投稿を残す、従来の確認操作を維持します。準備中も停止できます。[読み上げの制限と計測](BACKUP_VOICE.md)。

## ゲーム

ゲームを選ぶ画面の **「チップの残高・譲渡」** から残高・履歴や譲渡画面を開けます。無料ゲームはゲーム選択の一覧から利用できます。

掛け枚数は選択欄で変更し、開始や予想のボタンで実行します。残高不足で開始できない場合は、選択欄から残高内の枚数を選んでください。10枚未満では掛け枚数の選択欄を無効にします。残高の更新や無料ゲームへの案内は維持しています。前の版のボタンが残っていても、現在の権限・セッション・残高などの検証は引き続き働きます。

## 更新と確認範囲

`/admin → バージョン管理` から手動更新してください。コマンド数、データ形式、依存、ENVは変更しません。画面構造・操作・権限拒否は自動テストで確認しています。Discord実機での幅・フォント・折り返しは未確認です。

## v6.0の補足

管理ホームの設定選択は15機能と「全機能の操作ガイド」の計16項目、直接開くスラッシュコマンドの操作は15個のままです。カテゴリ画面からもガイドを開けます。チップ履歴・管理者の調整履歴でも、ページ移動と戻るを1行3ボタン以内に分けます。


## v6.13 運用画面

脆弱性診断は対象・詳細・JSON保存を1つの選択欄へ集約し、診断/ページ移動と戻り先を合わせて3行にします。勧告詳細も同じ行構成です。バージョン管理は概要・容量・手順を選択欄で切り替え、変更内容はカード内のリンクから開きます。更新ボタンは1行2つまでです。[操作と比較](OPERATIONS_UI.md)。


## v6.14 一般機能と卓管理

卓・キャラシの入口とPC一覧は関連操作を選択欄へまとめます。4目並べは列の選択欄と3つの操作ボタンの2行になり、満杯の列は表示しません。列を選ぶと1手進みます。盤面の左から1〜7列と空きマス数で選べます。予定・日程調整・卓・画像・読み方は主情報と詳細を別項目へ分けます。[変更点と8画面の比較](MEMBER_EXPERIENCE.md)。


## v6.15 ガイドと音声測定

使い方は機能/案内の種類の2つの選択欄と、機能を開く/メニューへのボタンを合わせた3行です。音声測定は上段の開始・状態更新・履歴を固定し、結果の詳細は選択欄から開きます。未測定画面に無効な中断ボタンを常時並べず、測定中にだけ中断の操作を表示します。確認内容は先頭です。[操作と比較](GUIDED_RECOVERY.md)。
