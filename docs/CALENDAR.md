# 予定表の使い方

公開投稿の **「カレンダーを開く」** で、本人だけの画面を開きます。管理者が予定を作成・編集するときは **`/admin → 予定表`** から開いてください。

## 月・日付から見る

「前の月／今月／次の月」で切り替え、「月を指定」で直接移動できます。「今日の予定」は日本時間の今日、「日付を選ぶ」は指定した日で絞ります。「月全体に戻る」で絞り込みを解除します。

カレンダー画像には1日3件と残り件数を表示します。予定を選ぶと完全な予定名・時刻・場所・説明を確認できます。「一覧表示」では文字で確認でき、件数が多い場合はページを切り替えます。

## 名前・場所・説明から探す

1. 予定一覧の **「検索・取り出し → 予定を検索」** を押す。
2. 検索語を入力する。例：`セッション VC3`。
3. 一致した予定を選んで詳細を見る。予定の一覧へ戻っても検索条件とページを維持します。

検索は、選んでいる予定表の**全期間**が対象です。検索語をスペースで区切ると、すべての語を含む予定に絞ります。予定名・場所・説明をまとめて照合し、全角・半角と英字の大小を揃えて探します。検索語は80文字までです。

「検索語を変える」で再検索、「検索を解除」で元の月・日付へ戻ります。空欄で検索しても解除できます。「今日の予定」や新しい日付・月への移動でも検索を解除します。

## 似た予定を複製する（管理者）

1. `/admin → 予定表` で予定を選ぶ。
2. **「複製して編集」** を押す。
3. 元の予定名・日付・時刻・場所・説明が入ったフォームで、日付などを直して送信する。

フォームを送信するまで新しい予定は作りません。元の予定は残り、新しいIDの予定として保存します。入力ミスは内容を保持して再入力できます。操作中に元の予定が変更・削除された場合は、複製を開き直してください。

## 端末のカレンダーへ取り出す

1. 取り出したい月・日付を表示するか、検索で対象を絞る。
2. **「検索・取り出し」** で範囲と件数を確認する。
3. **「カレンダーファイルを作る」** を押し、`astral-calendar.ics` を端末へ保存する。
4. `.ics` に対応したカレンダーアプリの読み込み機能を使う。

表示範囲の**全ページ分**を取り出します。選んだ予定表以外の予定は含めません。終日は日付、時刻付きは日本時間をUTCへ変換して記録し、端末ではアプリのタイムゾーンで表示されます。翌日終了にも対応します。

ファイルはその時点の控えです。Botの編集内容とは自動同期せず、通知・招待も追加しません。もう一度取り込む場合の上書きや重複はアプリによって異なるため、取り込み先で確認してください。0件の場合は作成できません。

ファイルは本人だけの返信へ添付します。ダウンロード後のファイルには予定の場所・説明も含まれるので、共有先を選んでください。

## 共有と権限

公開投稿を閲覧できる人は、その投稿の予定表を全期間で閲覧・検索・取り出せます。公開投稿から開いた画面は、管理者でも閲覧専用です。編集や複製は `/admin` から行います。

予定の変更後は送信済みの投稿を更新します。投稿更新に失敗しても保存した予定は残るため、「投稿を管理」で設置先の権限やメッセージを確認してください。実際の投稿がある場合は「投稿URLで復旧」を使い、同じ予定表を重ねて送らないようにします。

画面の操作期限は10分です。管理者は同じチャンネルから開き直すと期限内の続きへ戻れます。公開画面は元の投稿から開き直してください。再起動すると画面や入力途中の下書きは終了しますが、保存した予定は残ります。
