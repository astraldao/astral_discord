# 予定表の使い方

文字の一覧には「表示N件 / 全M件」を表示します。「全」は現在の月・日付・週・30日・検索条件に合う全件数で、「表示」は現在のページの件数です。

表示改善の根拠と未実装の候補は、開発向けの[カレンダー比較調査](CALENDAR_RESEARCH.md)にまとめています。

**`/menu → 予定表`** で、このチャンネルの共有予定表を選べます。公開投稿の **「カレンダーを開く」** からも、本人だけの画面を開けます。管理者が予定を作成・編集するときは **`/admin → 予定表`** から開いてください。

## 操作を探す

月移動・ページ移動・前後の予定はボタンで操作します。一覧の「追加・検索・その他の操作」（閲覧用は「検索・日付・その他の操作」）、詳細の「予定の操作を選ぶ」、検索整理画面の「保存・管理の操作を選ぶ」から、補助操作を選んでください。以下の手順の操作名は、ボタンまたはその画面の選択欄の項目です。

## メニューから共有予定表を選ぶ

共有先のテキストチャンネルで `/menu → 予定表` を開くと、確認できる共有投稿を予定表ごとに表示します。10件ずつページを切り替えられ、「共有投稿を確認」で再取得できます。ほかのチャンネルの予定表、送信結果未確認の投稿、元の投稿が見つからない予定表は表示しません。

閲覧・メッセージ履歴の権限が必要です。Botにも同じ権限を付けてください。選択時にも元のBot投稿を確認します。管理者がメニューから開いても編集はできません。予定表の画面にある「予定表を選ぶ」で選択へ戻れます。

## 月・週・30日分・日付から見る

「日付から探す」で、予定がある日を件数・予定名から選べます。「すべての日を表示」で空の日も選択でき、最大25日ずつページを切り替えます。月移動・日付入力・今日への移動にも対応し、選ばず戻ると元の表示範囲や検索・ページを維持します。

月画像で当月の予定帯が3段に収まらない場合は、同じ入口が **「省略のある日から探す」** に変わります。画面にも案内が出るので、補助操作の選択欄から開いてください。省略のある日だけを選べ、日付の説明に画像の `+N件` を表示します。日付を選ぶと、その日の予定名と時刻を文字で表示し、8件を超える場合もページを送って全件確認できます。

「予定がある日を表示」で通常の日付選択へ切り替え、さらに「すべての日を表示」で空の日も選べます。日付を選ばず戻ると、元の月画像を保持します。日付選択中に月を移動すると省略日の絞り込みを解除します。前後の月だけの省略はこの絞り込みに含めず、その月へ移動して確認してください。

「表示を切り替える」で **月カレンダー・月の一覧・週間・今日から30日** を選びます。月の選択は月全体の表示へ戻ります。

月画像は予定の配置を見渡すための表示です。スマホで文字が小さいときや予定名が省略されているときは、**「表示を切り替える → 月の一覧」** で予定名・時刻を文字で読めます。月画像の上にも、この操作を案内します。詳細は予定の選択欄から確認してください。

週間は日曜〜土曜で、「前の週／今週／次の週」で移動します。選択中の日があればその週、今月なら今日、別の月なら1日を含む週から開きます。今日から30日は、日本時間の表示開始日から29日後までを日付順の文字で表示し、「今日から更新」で更新します。今日の予定は時刻にかかわらず含みます。2000〜2099年の境界は表示範囲を短くします。

週・30日分では、複数日の終日予定や前日から続く翌日終了の予定も含め、1件として表示します。範囲前に始まった予定は「期間前から続く予定」と表示します。午前0時で終了した予定は翌日の分へ含めません。従来の月・日別の集計は維持します。

「前の月／今月／次の月」で切り替え、「月を指定」で直接移動できます。「今日の予定」は日本時間の今日、「日付から探す → 日付を入力」は指定した日で絞ります。「月全体に戻る」で絞り込みを解除します。

カレンダー画像には最大3段の予定帯と残り件数を表示します。複数日の終日予定は週ごとに横につながり、月の件数では1つの予定として数えます。予定を選ぶと完全な予定名・時刻・場所・説明を確認できます。「月の一覧」では文字で確認でき、件数が多い場合はページを切り替えます。

週ごとに必要な高さを計算し、予定がない週の空白を縮めます。すべての予定カードで上段に開始時刻、または「終日」を表示します。混んでいる週でもこの情報を省かず、名前は1行、空きがある週は最大2行にします。3段の帯と残り件数は維持します。時刻の行を確保するため、従来より高くなる週もあります。同名の単日予定を自動で1件にまとめることはありません。

文字の一覧は同じ日付の予定を見出しの下にまとめ、各行に時刻と完全な予定名を表示します。複数日の予定は開始日だけでまとめず、同じ期間ごとに分けます。翌日終了の時刻や、週・30日分の「期間前から続く予定」も残します。1ページ8件で、ページを送った先にも日付の見出しを表示します。

詳細では「前の予定／次の予定」で今の表示範囲を移動でき、「この予定だけ保存（ICS）」で1件だけ取り出せます。移動後に一覧へ戻ると、その予定のページを表示します。

## 見出しと予定カード

年・大きな月表示・予定表名を左側、当月件数のバッジを右側に配置します。曜日は淡い背景、今日の日付は青い丸、選択中の日は背景と下線で区別します。

予定カードは角と余白を揃え、当月の予定には色のアクセントを付けます。続きがある端は四角くし、複数日に続く予定だと分かる形にします。前後の月の予定は淡い色のままです。収まらない予定名は画像下に当月優先で最大3件・各2行まで補足します。補足も収まらない場合は省略記号と一覧への案内を表示し、完全な予定名と全件の詳細は各月の一覧から確認できます。

補助文字・時刻・前後月の予定名は、淡い予定帯でも読みやすい濃さにしています。補助文字色は実際に使う背景色に対して4.5:1以上のコントラストを確保します。これは配色の確認で、端末上の縮小表示やアクセシビリティ全体の適合を保証するものではありません。

## 月末から翌月を見渡す

月末が土曜日の場合も、その下に翌週を1行追加し、翌月1〜7日を表示します。たとえば2026年10月は10月31日（土）の下に11月1日（日）〜7日（土）が続きます。ほかの月も、月初・月末の余白に入る前後の月の日付と予定を表示します。全体は日曜始まり・最大6週です。

前後の月は日付と予定名を薄字、予定の帯を淡い色、背景を薄い色にします。隣の月の先頭には `11/1` のように月も表示します。月をまたぐ複数日の予定は、同じ週内で段をそろえ、当月部分と前後の月の部分を色の濃さで区別します。

画像上部の「当月N件」は当月と重なる予定の件数です。前後の月だけの予定は含めません。薄字の予定の詳細はその月へ移動して確認してください。予定の選択欄・月の一覧・月単位のICS保存の対象も当月のままです。検索や週間・30日表示は引き続きそれぞれの表示条件を使います。

表示するのは同じ予定表の予定だけです。別の予定表の内容は取り込みません。前後の月でも最大3段と残り件数を表示し、長い名前の補足は当月の予定を優先します。翌日終了の時刻付き予定は、従来どおり開始日に表示します。画像の読み上げ用説明にも前後の月を区別して記載します。

## 予定の色を変更する（管理者）

`/admin → 予定表 → 予定の詳細` の色の選択欄から、青・緑・赤・紫・黄・グレーを選べます。自動の色は予定名で決まり、用途の目印として管理者が変更できます。閲覧用の画面は変更できません。

共有済みの画像・文字の一覧・詳細へ反映し、日時や名前の編集でも保持します。複製・繰り返し追加は色も引き継ぎます。ICSへ色は書き出さず、取り込みの新規予定は自動色です。既存の同じ予定を取り込んだ場合は、重複として追加せず現在の色を保持します。

以下の「検索・取り出し」は、管理者画面では「検索・整理」です。共有・投稿管理・名前変更・ICS取り込みもここにまとめています。予定の追加は一覧から操作できます。

## 名前・場所・説明・日付から探す

1. 予定一覧の操作の選択欄で **「予定を検索」** を選ぶ。「検索・取り出し」（管理者は「検索・整理」）からも開けます。
2. 検索語を入力する。例：`セッション VC3`。
3. 一致した予定を選んで詳細を見る。予定の一覧へ戻っても検索条件とページを維持します。

検索は、選んでいる予定表の**全期間**が対象です。検索語をスペースで区切ると、すべての語を含む予定に絞ります。予定名・場所・説明をまとめて照合し、全角・半角と英字の大小を揃えて探します。検索語は80文字までです。

| 入力例 | 検索条件 |
|---|---|
| `日付:2026/10/17` | その日に重なる予定 |
| `月:2026/10` | その月に重なる予定 |
| `月:2026/10 図書館` | その月の予定で、予定名・場所・説明に「図書館」を含むもの |

条件の日付は2000〜2099年、区切りは `/` と `-` に対応します。複数日の予定や前日から翌日に続く予定も対象にし、午前0時で終わる予定は翌日分へ含めません。日付だけの語は従来どおり本文の文字として探すため、日時条件には `日付:` / `月:` を付けてください。不正な日付を入力した場合は元の検索結果を保持します。

「検索語を変える」で再検索、「検索を解除」で元の月・日付・週・30日分とページへ戻ります。予定が減った場合は有効な最終ページへ調整し、再開時に30日分の開始日が変わった場合などは1ページ目に戻ります。空欄で検索しても解除できます。「今日の予定」や新しい表示への移動でも検索を解除します。

## 連休・複数日の予定を追加する（管理者）

「予定を追加」または「予定を編集」で、日付に `2026/10/30〜2026/11/02` と入力し、時刻を空欄にします。開始日・最終日を含む最大31日です。単日の `2026/10/30` も引き続き使えます。

週・月をまたいでも1つの予定として保持し、該当する各日・各月に表示します。日付を単日に直せば、複数日の指定を解除できます。複製と繰り返し追加では期間も引き継ぎます。時刻付きの予定は従来どおり1日を起点にし、終了が早い時刻なら翌日終了です。

## 定例の予定をまとめて追加する（管理者）

1. 予定の詳細で **「繰り返して追加」** を押す。
2. 毎日・毎週・隔週・毎月を選び、「追加する件数を入力」で1〜26件を指定する。初期値は毎週4件。
3. **「追加する日付を確認」** で全日程と、既存予定との重なりを確認する。
4. **「このN件を追加」** でまとめて保存する。

元の予定は件数に含めず、次の日付から追加します。毎月は元の日付を維持し、31日など存在しない月を飛ばします。たとえば10月31日から毎月2件なら、12月31日・翌1月31日を追加します。

元の予定と追加した予定は独立し、後から1件ずつ編集・削除できます。将来の予定を自動生成したり、通知を予約したりする機能ではありません。保存上限は1予定表200件・全体1000件、対応年は2000〜2099年です。元の予定や予定表が確認後に変更された場合は全件を保存せず、確認し直します。

重なりは終日・複数日・翌日終了も含めて判定します。終了時刻がない予定は開始時刻だけで比較します。重なりの案内は確認用で、自動的に予定を省いたり変更したりしません。

## 似た予定を複製する（管理者）

1. `/admin → 予定表` で予定を選ぶ。
2. **「複製して編集」** を押す。
3. 元の予定名・日付・時刻・場所・説明が入ったフォームで、日付などを直して送信する。

フォームを送信するまで新しい予定は作りません。元の予定は残り、新しいIDの予定として保存します。入力ミスは内容を保持して再入力できます。操作中に元の予定が変更・削除された場合は、複製を開き直してください。

## ICSファイルから取り込む（管理者）

1. 取り込み先の予定表を `/admin → 予定表` で開く。
2. **「検索・整理 → ICSファイルから取り込む」** で、UTF-8の `.ics` ファイルを1つアップロードする。
3. 新規件数・重複件数を確認する。全ページの日時・予定名と、選択欄から場所・説明を確認できる。この時点では保存しない。
4. **「新規N件を取り込む」** で、新しい予定だけをまとめて保存する。

256KiB・200予定の小さい方が上限です。1予定表200件・全体1000件の既存の上限も適用します。読み込みは同時に1件、次のファイルは10秒後からです。未保存の確認画面は最大4人分で、「取り込まず戻る」で破棄できます。

予定名・日付/終了日・時刻・場所・説明が同じ予定は、既存とファイル内の両方で重複を除外します。UIDによる更新や同期はしません。内容を変更して取り込み直すと別の予定として追加されるため、プレビューを確認してください。既存予定の上書き・削除はありません。

| 対応する日時 | 扱い |
|---|---|
| 終日と複数日の終日 | 開始・最終日を含む最大31日 |
| UTC（末尾Z）/ TZID=Asia/Tokyo | 日本時間へ変換して表示 |
| タイムゾーンなし | 日本時間として扱う |
| 時刻付きの翌日終了 | 開始後24時間未満まで |

2000〜2099年、予定名80文字・場所100文字・説明500文字、分単位の日時に対応します。このBotから出したICSも、容量・件数内なら取り込めます。大きいファイルは取り込む月や予定を分けて書き出してください。

繰り返し規則・例外日・取消・秒単位・未対応タイムゾーン・不正な予定を含むファイルは、一部だけ保存せず全体を拒否します。通常の予定として書き出し直してください。通知・参加者・添付・URL属性などは取り込まず、外部リンクの取得や通知の実行はしません。ファイルの元データと取得URLを保存・ログ出力せず、未保存の候補は操作期限後に使えず、開き直し・再起動で破棄します。

取り込み後の内容は、その予定表の既存の共有先にも表示します。個人用カレンダーを取り込む場合は、予定表の共有先を確認してから保存してください。確認中に予定表が変わった場合は、ファイルを選び直します。

## 端末のカレンダーへ取り出す

1. 取り出したい月・日付・週・30日分を表示するか、検索で対象を絞る。
2. **「検索・取り出し」** で範囲と件数を確認する。
3. **「カレンダーファイルを作る」** を押し、`astral-calendar.ics` を端末へ保存する。
4. `.ics` に対応したカレンダーアプリの読み込み機能を使う。

表示範囲の**全ページ分**を取り出します。選んだ予定表以外の予定は含めません。範囲と重なる予定は元の開始日・終了日のまま取り出します。終日は日付、時刻付きは日本時間をUTCへ変換して記録し、端末ではアプリのタイムゾーンで表示されます。翌日終了にも対応します。

ファイルはその時点の控えです。Botの編集内容とは自動同期せず、通知・招待も追加しません。もう一度取り込む場合の上書きや重複はアプリによって異なるため、取り込み先で確認してください。0件の場合は作成できません。

ファイルは本人だけの返信へ添付します。ダウンロード後のファイルには予定の場所・説明も含まれるので、共有先を選んでください。

## この投稿の共有を停止する（管理者）

1. `/admin → 予定表` から予定表を選び、**「検索・整理 → 投稿を管理」** を開く。
2. 対象の投稿を選び、**「この投稿の共有を停止」** を押す。
3. チャンネル・表示月と影響範囲を確認し、共有停止を確定する。

この投稿の共有登録を先に解除するので、元のボタンと開いている閲覧画面は使えなくなり、メニューの候補からも外れます。予定表・予定データ・ほかの共有投稿は残します。後から共有し直す場合は、新しく送信先を選んで確認します。

その後、元のBot投稿の削除を試みます。削除できない・結果を確認できない場合も共有登録は戻しません。案内のリンクから元の投稿を確認し、残った画像・テキストを管理者が削除してください。取り出し済みファイル、スクリーンショットやコピーは取り消せません。

確認をキャンセルした場合や、確認途中で管理画面を開き直した場合は共有停止を実行しません。内容や権限が変わっている場合も、もう一度確認してください。

## 共有と権限

公開投稿を閲覧できる人は、その投稿の予定表を全期間で閲覧・検索・取り出せます。公開投稿から開いた画面は、管理者でも閲覧専用です。編集や複製は `/admin` から行います。

予定の変更後は送信済みの投稿を更新します。投稿更新に失敗しても保存した予定は残るため、「投稿を管理」で設置先の権限やメッセージを確認してください。実際の投稿がある場合は「投稿URLで復旧」を使い、同じ予定表を重ねて送らないようにします。

画面の操作期限は10分です。管理者は同じチャンネルから開き直すと期限内の続きへ戻れます。公開画面は元の投稿か `/menu → 予定表` から開き直してください。再起動すると画面や入力途中の下書きは終了しますが、保存した予定は残ります。

### 長い予定名の補足（v4.4.1）

月画像の枠内で省略した名前を、下部に日付・開始時刻付きで最大8件まで全文表示します。別日の同名予定は分け、週をまたぐ同一予定は補足を重複させません。残りがある場合は件数を表示します。隠れた予定・終了日時・場所は下のメニューから確認してください。[表示例](V4_4_1.md)。

## v5.0 整理・復元（管理者）

「検索・整理 → 整理・復元」に、日付の一括移動・変更履歴・時間の重なりをまとめました。閲覧者には表示しません。予定の詳細からは「この予定の履歴」でも開けます。

新規登録や候補日への回答を増やす機能ではなく、確定した予定を管理します。候補日・回答の収集は[日程調整](DENSUKE.md)を使います。[全手順・履歴の保存上限](V5.md)。

## 重なりから予定を直す（v5.3）

重なりの確認画面で、このページの予定を選ぶと詳細へ進めます。編集後は「重なりの一覧へ」で戻れます。予定表が変わっていれば重なりを再計算します。閲覧者にはこの管理導線は表示しません。
