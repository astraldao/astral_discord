# v5.1 メニューから対処までを短くする

普段の操作、管理、困ったときの復帰を見直しました。2つのコマンドと既存機能・データを引き継ぎます。

| やりたいこと | 入口 |
|---|---|
| 説明から機能を見つける | `/menu → 目的・説明から機能を探す` |
| 管理する設定を直接開く | `/admin → 設定名・目的から直接開く` |
| 失敗した機能を開き直す | メニューのエラー画面 → 対象機能を開き直す |
| 操作がうまくいかない理由を調べる | `/menu → 使い方 → 操作を選ぶ → うまく動かないとき` |
| 動作診断の結果から対処を探す | `/admin → 動作診断 → 対処の手順` |
| 実行用の依存の勧告だけを見る | `/admin → 脆弱性診断 → 診断を開始 → 実行用` |
| 診断結果を手元に保存する | 完了した脆弱性診断 → 全件JSONを保存 |

カテゴリ・最近使った機能・コマンドの直接操作も維持します。カテゴリを覚えていなくても、目的の説明から機能を開けます。読み上げ画面を開くだけでは開始せず、更新・再起動・送信なども各画面で明示的に実行します。

エラー画面の「開き直す」は手動操作です。失敗した保存などを自動で繰り返す機能ではありません。読み上げの停止は再試行ボタンには含めません。使い方やメニュー自体の表示で履歴の保存期間を延ばしません。

動作診断の対処は診断時点の結果に基づきます。未確認のファイルを故障とは断定せず、権限や設定・導入手順・測定へ案内します。設定を直したら診断を更新してください。

脆弱性診断の絞り込みは取得済みの結果だけを使います。絞り込みに該当がなくても、全件の勧告が0件になったとは表示しません。「全件JSONを保存」は絞り込みに関係なく全結果を保存し、追加照会や自動修正はしません。名前・版を含むパッケージ構成が入るため、共有前に内容を確認してください。サイズ上限は512KiBです。

`/admin → バージョン管理` から通常の手動更新で反映できます。ENV変更・新しい直接依存・データ移行は不要です。既知の脆弱性に対応し、間接依存undiciを6.29.0から6.29.1へ更新しています。本番Discordでの表示・動作は更新後に確認してください。
