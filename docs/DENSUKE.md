# 日程調整を作成・共有する

管理者が `/admin → 予定・卓 → 日程調整` から伝助のイベントを作成します。

## 内容を入力する

1. 初回は「控えメールの宛先」で管理用のメールアドレスを保存する。
2. 回答の選択肢を「○△×」「○×」「◎○△×」から選ぶ。
3. 「イベント内容を入力」でイベント名と候補日程を入力する。候補は1行に1候補。
4. 内容確認の画面で確認し、「この内容で作成」を押す。

説明とパスワードは任意です。パスワードは半角英数字8文字以内です。入力の修正が必要な場合は「内容を修正」から直せます。

固定メールは再起動・コード更新後も保持します。ほかの管理者が宛先を変更した場合は、内容を確認し直してから作成します。

内容・回答の選択肢・控えメールの宛先を変更した後は、新しく表示された確認画面を使ってください。以前の画面の作成・共有・取消ボタンや古い入力フォームは拒否され、現在の内容を表示します。内容・メール設定の入力フォームを複数開いた場合は、それぞれ最後に開いたフォームだけ送信できます。メール設定は保存時にも、フォームを開いたときの宛先から変更されていないことを確認します。別の管理者が変更した場合は、最新のフォームを開き直してください。同じ内容の確認画面を開き直すだけなら、確認ボタンは引き続き使えます。

## 作成結果を確認する

成功すると回答用URLと、取得できた場合は編集用URLを本人だけの画面に表示します。画面を開き直すと、有効期限内なら続きから確認できます。操作画面の期限は最初に開いてから10分で、開き直しても延長しません。

作成は1人5分に1回・全体で1分に1回までです。「作成中」の画面更新や送信前の権限確認で止まった場合は、外部確認を送らず内容確認へ戻り、この待ち時間を消費しません。外部確認を始めた場合の制限は維持します。

作成に成功した後の画面表示だけが失敗しても、作成を繰り返しません。同じチャンネルで日程調整を開き直し、結果を確認してください。

## 作成結果が未確認の場合

伝助で作成されている可能性があるため、Botは自動再作成しません。控えメールを確認し、イベントがあれば「作成済みURLを登録」または「メールのURLを登録」で回答用URLを登録します。再起動後も、新しい画面から回答用URLを登録できます。

復旧に編集用URLは使いません。登録しただけではチャンネルに投稿しません。

## 回答用URLを共有する

「回答URLを共有」を押すと、作成したチャンネルへ回答ページへのボタンを投稿します。編集用URL・パスワード・メールアドレスは投稿しません。

| 表示 | 状態と次の操作 |
|---|---|
| 回答URLは共有済み | 投稿の成功を確認できた状態。同じボタンから再送しません |
| 共有結果は未確認 | 送信中、または投稿結果が分からない状態。共有先で投稿を確認してください。Botは再送しません |
| 回答URLを共有 ＋ 共有できなかった案内 | Discordが投稿を明確に拒否した状態。共有先とBotの閲覧・送信・埋め込み権限を直してから、同じボタンで再試行できます |

共有結果が分からず必要な場合は、表示されている回答用URLを手動で共有できます。編集用URLは非公開のまま扱ってください。

作成結果の未確認は「イベントが作成されたか」、共有結果の未確認は「回答ページをチャンネルへ投稿できたか」の違いです。共有に失敗しても、イベントを作り直す必要はありません。
