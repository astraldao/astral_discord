# Botのプロフィールバナーを変更する

管理者がDiscord上で画像を選び、Botのプロフィール上部のバナーに使用できます。
これは **Bot全体のプロフィール** の変更です。入室パネルや予定表の画像、サーバー自体のバナーは変更しません。

## 画像を登録する

1. **`/admin → 外観・投稿 → Botのバナー`** を開く。
2. **画像を選ぶ** を押し、端末にあるPNGまたはJPEGを1枚アップロードする。
3. 現在のバナーと **変更後のプレビュー · 未適用** を見比べる。
4. よければ **この画像を適用** を押す。

ファイルを選ぶだけでは公開されません。変更するには最後の適用操作が必要です。
選び直したい場合は「画像を選び直す」、適用せず戻る場合は「変更せず戻る」を使ってください。

- PNG・JPEG、4MiB以内。
- 横長の **600×240px以上** を推奨します。縦横8192px以内、合計約1600万画素まで。
- 文字や顔などは画像の中央寄りに配置すると、端が切れにくくなります。
- プレビューは画像全体です。プロフィールでの実際の切り抜き・表示サイズはDiscordに従います。
- GIF・WebP・HEIC・SVGなどは、PNGかJPEGに保存し直してから選んでください。

画像URLの貼り付け、メッセージ本文を読むIntentの設定、Botの再起動は不要です。
操作画面は本人だけに表示されます。最新のDiscordアプリで操作してください。

## 確認・解除する

**現在を確認** で、Discordに設定されている最新のバナーを取得します。
他の管理者がプレビュー中に変更した場合は、古い確認内容のまま適用せず、現在の画像を確認してからやり直します。

解除する場合は **バナーを解除 → 確認画面でバナーを解除** を押します。
画像は削除され、バナーなしのプロフィールになります。確認画面で「変更せず戻る」を押せば解除しません。

適用した画像はDiscord側のBotプロフィールに保存され、Botの再起動・GitHubからの更新でも維持されます。
未適用の候補は一時的にメモリ内だけに保持し、操作終了・10分の期限切れ・Bot再起動で破棄します。
**操作を終了** で候補と操作画面を閉じ、現在のバナーをそのまま残せます。

## 困ったとき

| 表示・症状 | 操作 |
|---|---|
| 管理者専用と表示される | 現在のAdministrator権限と、操作元チャンネルの閲覧権限を確認する |
| 画像を選べない・フォームが開かない | Discordアプリを最新版にし、`/admin` から開き直す |
| PNG・JPEGを選ぶよう表示される | 対応形式へ保存し直して再アップロード。名前を変えるだけでは形式は変わりません |
| 4MiB・画像サイズの制限 | 端末の画像編集機能などで縮小・再保存する。既存のバナーは変更されません |
| 取得できない | アップロードし直す。画像の期限切れや通信失敗では既存のバナーを維持します |
| 他の操作でバナーが変わった | 「現在を確認」で最新画像と候補を見比べ、必要なら改めて適用する |
| 変更直後と表示される | 表示された秒数だけ待つ。変更は全管理者で共有し、成功後は60秒間隔を設けています |
| 反映を確認できない | 連打せず「現在を確認」で結果を見る。通信が切れる前に反映済みの場合があり、確認するまで適用ボタンは無効になります |
| 古い画面・期限切れ | 管理メニューの「Botのバナー」から開き直す。期限切れの候補は再アップロードする |
| 画面が使用中 | 他の管理者が「操作を終了」するか、最大10分の期限切れを待つ |
| Discordで古い画像が見える | Botのプロフィールを閉じて開き直し、しばらく待って再確認する |

Bot全体で同時に1件だけ変更を実行します。アップロード中に管理者権限が失われた場合は、候補を表示・適用しません。
画像の形式・構造・サイズをBotで確認し、最終的なデコードと反映はDiscordに委ねます。
開発環境では操作・権限・形式・サイズ・競合・失敗時のテストを行っています。Discord実機のプロフィール変更とモバイル表示は未検証です。
