# v5.0 確定した予定を整理・復元する

予定表を管理する操作を追加しました。候補日と回答を集める[日程調整](DENSUKE.md)とは役割を分けています。出欠機能の追加はありません。

`/admin → 予定表 → 予定表を選ぶ → 検索・整理 → 整理・復元` で開きます。管理者専用です。現在の閲覧者用の予定表は従来どおり使えます。

| やりたいこと | 操作 |
|---|---|
| 選んだ予定を翌週へずらす | 日付をまとめて移動 → 対象を選ぶ → 7日後の移動前後を確認 → 移動 |
| 日付を前へ戻す | 移動する日数を変更 → `-7` などを入力 → 確認 → 移動 |
| 誤った編集・削除を戻す | 変更履歴・復元 → 履歴を選ぶ → 復元する内容を確認 → 復元 |
| ある予定だけの履歴を読む | 予定の詳細 → この予定の履歴 |
| 時間が重なる予定を探す | 時間の重なりを確認 |
| 保存された履歴を消去する | 変更履歴・復元 → この予定表の履歴を消去 → 確認 |

## 日付の一括移動

移動対象の候補は、開いたときの月・日・週間・今日から30日・検索結果です。検索結果は全期間が対象です。先に一覧の条件を決めてください。

25件ずつ表示する選択メニューから、合計26件まで選べます。ページを移っても選択を保持し、「選択をすべて解除」でやり直せます。日数は前後365日以内・0以外です。予定の期間・時刻・色・場所・説明とIDを保持し、日付だけ移します。複数日や翌日終了の予定も対応します。

保存前に、全対象の移動前後を5件ずつ確認できます。「このN件を移動」は全ページの選択を1回で保存します。選択外の既存予定と重なる移動先があれば件数を表示します。同じ移動量なので選択内同士の重なりは変わらず、警告件数には含めません。

予定を複製する操作ではありません。別の操作で予定表が変わった場合は保存せず、対象とプレビューを確認し直します。一覧へ戻ると元の表示条件を維持するため、移動後の日が条件外なら表示月などを変えてください。アプリ再開で未確定の移動を実行することはありません。

## 変更履歴と復元

この版へ更新した後の、既存予定の編集・色変更・削除・一括移動を記録します。新規登録・取り込み・予定表名や投稿の変更は記録しません。操作した人のID・名前は保存しません。

履歴の詳細では、予定名・日時・場所・説明・色を変更前後で確認できます。複数件の履歴では1件ずつページを切り替えます。復元確認の「このN件を復元」は、その履歴の全件をまとめて変更前の内容へ戻します。削除した予定も元のIDで戻します。

後から編集された予定や、同じIDが既に存在する削除履歴は復元できません。確認後に予定表が変わった場合も保存を拒否します。復元済みの履歴と、復元操作そのものは再適用できません。必要な追加修正は予定の編集から行ってください。保存件数の上限も守ります。

**保存上限は予定表ごと20操作、全体50操作・500スナップショット・512KiBです。** 一括変更の前後は複数のスナップショットになります。上限や予定表ファイル全体の2MiB上限に応じて古い履歴を消すため、保持期間や20操作分が常に残ることは保証しません。履歴はバックアップや監査ログの代わりにはなりません。

履歴は管理用画面だけに表示し、共有投稿・カレンダー画像・ICSには含めません。古い説明なども履歴には保持されます。削除する場合は履歴消去を使ってください。

## 履歴の消去

確認してから、この予定表全体の履歴を消去します。ある予定に絞った履歴画面からでも、その予定表の履歴すべてが対象です。確認画面で対象を明示します。

現在の予定・共有先は残します。消去後は、削除済みの予定をこの機能から復元できません。取り出し済みのファイルやサーバー側のバックアップは別途管理してください。

## 時間の重なりを確認

現在の表示範囲ではなく、選んだ予定表の全予定を比較します。重なりの総数を表示し、先頭100組まで5組ずつ確認できます。重なっていても自動削除・移動はしません。

終日はその日全体、終了未指定は開始時刻だけ、翌日終了と複数日も実際の日付区間で比較します。終了と次の開始が同じ時刻なら重なりません。参加者や場所の競合を判定する機能ではありません。

## 更新

`/admin → バージョン管理` から手動更新します。既存の予定・共有先・日程調整を引き継ぎます。依存追加・ENV変更・手作業のデータ移行は不要です。過去の操作の履歴はさかのぼって作られません。
