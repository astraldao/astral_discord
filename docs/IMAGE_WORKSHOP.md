# 画像工房（v6.11）

PNG・JPEGを、絵文字・スタンプ・共有用に整形します。`/menu` の選択欄、または操作「画像工房」から開けます。外部AIやAPIキーは不要です。

## 使い方

1. 「画像を選ぶ」でPNG・JPEGを1枚アップロード。
2. 用途と仕上げを選択。選択だけでは変換しません。
3. 「画像を作成」でプレビューと添付ファイルを確認し、画像を保存。
4. 別の仕上げを試す場合は、設定を変えて元画像から作り直します。
5. 「操作を終了」でBotが保持している画像を破棄します。

| 用途 | 出力 |
|---|---|
| 絵文字 | 128×128px・PNG・256KiB以内 |
| スタンプ | 320×320px・PNG・512KiB以内 |
| 共有用 | 長辺最大1024px・JPEG・512KiB以内。必要に応じて画質・サイズを自動調整 |

「全体を残す」では、PNGは透明な余白を足して正方形にし、共有JPEGは縦横比を保ちます。切り抜きは中央・上・下・左・右を基準に矩形の範囲を調整します。元の透過PNGの透明部分はPNG出力に保持し、JPEGでは白い背景へ重ねます。絵文字・スタンプは小さい画像も指定サイズへ拡大し、共有用は拡大しません。

完成画像は本人だけに表示します。Discordの絵文字・スタンプへの登録は、保存後にDiscord側で行います。

## 入力・処理の制限

- PNG・JPEGを1枚、4MiB・約400万画素（4,194,304画素）以内。例：2048×2048px。
- アニメーションPNG、GIF、WebP、SVGなどは対象外。画像形式は実データで確認します。
- 原画像の向きを補正し、EXIF・位置情報・付加情報を出力へ引き継ぎません。
- ダウンロードは最大10秒、変換は最大15秒。同時変換1件で、待機列は作りません。
- 同じ人の作成は10秒間隔、全体は最低2秒間隔。音声処理中は終了後に作成します。
- 画面は最大20件、画像保持・取得中は最大4人分。操作開始から10分、明示終了、Bot再起動で保持を終了します。

作成中にメニューへ戻っても変換は続きます。別の画面を結果で上書きせず、完了後に画像工房を開き直すと保持中の結果を確認できます。用途や切り抜きを変えた場合は、前の完成画像を表示から外し、次の作成を待ちます。

画像をディスクや保存用JSONへ書き込みません。Botから送信済みの添付ファイルの取り扱いはDiscord側の保持に従い、Botの操作終了だけで完全削除することを保証するものではありません。閲覧権限のない人や他人の画面からは取得できません。

## 管理者向け

Botにチャンネルの閲覧・送信・埋め込み・ファイル添付権限を付与してください。スレッドではスレッド送信権限も必要です。

依存へ固定版 `sharp@0.35.5` を追加しています。通常の `npm ci` で対応プラットフォームのネイティブライブラリも導入するため、optional dependenciesを省略しないでください。Node.jsの要件は既存の24.17.0以上です。更新は従来どおり `/admin → バージョン管理` から手動適用します。追加依存の取得容量は更新画面で未確認と表示される場合があります。

変換は専用Nodeプロセスで実行し、同時1件・Sharpの並列度1・キャッシュ無効・JavaScriptヒープ64MiBとしています。ヒープ設定はネイティブ画像処理を含む総メモリの上限ではありません。入力バイト数と画素数、出力サイズを別に制限し、タイムアウト・終了・期限切れでは子プロセスを停止します。子へトークンや起動環境の秘密情報を引き継ぎません。Sharpの読み込みに失敗しても、Bot本体の起動とは分離しています。

## 表示の見本と検証

[画像工房のHTML見本](previews/workshop-v6_11.html)は、固定の架空画像を実際に変換し、送信データをHTMLにしたものです。再生成は `node scripts/preview-image-workshop.js > docs/previews/workshop-v6_11.html`。Discord実機のスクリーンショットではありません。

自動テストでは実際のSharp/専用プロセスによる変換・透過・切り抜き・向き補正・メタデータ除去と、取得先/サイズ制限・不正画像・権限/期限・再送/同時実行の制御を確認しています。Discord/Quaxly本番でのアップロード・添付の実表示は未確認です。
