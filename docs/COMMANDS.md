# コマンドの早見表

コマンドは **`/menu`（普段使い）** と **`/admin`（管理者専用）** の2つです。
表示される画面は本人だけに見えます。スマートフォンでも同じボタン・選択メニューを使えます。

## 普段の操作

| やりたいこと | 操作 |
|---|---|
| 操作の手順を調べる | `/menu` → 使い方 → 知りたい操作を選ぶ |
| 最近開いた機能へ戻る | `/menu` → 最近使った機能を開く（本人・同じチャンネル、最大3機能・10分） |
| VCへ入る | ロビーVCに参加 → `/menu` → VCに入る → 入室先を選択 |
| 入室予約を取り消す | 予約メッセージのキャンセル。見失ったら `/menu` → VCに入る |
| テキストを読み上げる | 聞きたいVCに参加 → 読みたいテキストチャンネルで `/menu` → 読み上げ → このチャンネルで開始 |
| 読み上げの状態を確認する | `/menu` → 読み上げ |
| 読み上げを一時停止・再開 | `/menu` → 読み上げ → 一時停止／読み上げを再開。今の文章を最後まで読んでから待機 |
| 読み方をチャット向けにする | `/menu` → 読み上げ → 読み方を「チャット向け」に選択 |
| 待機分だけ消去する | `/menu` → 読み上げ → 待機分を消去 → 確認時の待機分を消去 |
| 読み上げを止める | 読み上げ画面の「読み上げを停止」ボタン |
| このチャンネルの予定表を見る | `/menu` → 予定表 → 共有予定表を選ぶ |
| 今週・次の予定を見る | 予定表 → 表示を切り替える → 週間／今日から30日 |
| 日付を件数から選ぶ | 予定表 → 日付から探す → 日付を選択 |
| 月画像の `+N件` を確認 | 予定表 → 補助操作の「省略のある日から探す」→ 日付を選択 → 文字一覧 |
| 1件だけカレンダーへ保存する | 予定の詳細 → この予定だけ保存（ICS） |
| ゲームで遊ぶ・続きを開く | `/menu` → ゲーム → 遊ぶゲームや「続きから遊ぶ」を選択 |
| 画像を絵文字・スタンプ・共有用に整える | `/menu` → 画像工房 → 画像を選ぶ → 用途・仕上げ → 作成・保存 |
| 自分の名前の読み方を変える | `/menu` → 自分の読み方 |
| 残高・履歴を見る | `/menu` → 自分のチップ |
| チップを渡す | `/menu` → ゲーム → チップを渡す |

操作を省きたいときは `/menu` の任意項目 **「操作」** を使います。「VCに入る」「読み上げを開く」「ゲームを開く」「読み上げを停止」「自分の読み方」「自分のチップ」「このチャンネルの予定表」「画像工房」を直接選べます。
読み上げ画面を開けない場合も、「操作」で「読み上げを停止」を選ぶと停止できます。停止できるのは開始した本人か管理者です。元の読み上げチャンネルが削除された後でも、別の閲覧できるチャンネルから停止できます。

VCのロビーに未参加の場合は、ロビーを開くリンクと手順を表示します。参加したら「入室先を確認」を押して続けてください。閲覧できないロビーはリンクもIDも表示しません。

読み上げは画面を開いたチャンネルで開始します。「自分の読み方」は非公開画面の中で開き、元のゲーム画像も消去します。
メニューへ戻っても読み上げは続き、進行中のゲームも保持します。Botの再起動では読み上げとゲームは終了します。詳細は [読み上げの手順](BACKUP_VOICE.md) を参照してください。

## 管理の操作

`/admin` を開くと「予定表」「バージョン管理」が直接表示されます。初期設定前は「VC設定をはじめる」を優先します。再起動を含むほかの機能は、設定名または4つのカテゴリの選択欄から選びます。VC・音声設定などでは所属カテゴリへも戻れます。

「設定名・目的から直接開く → 全機能の操作ガイド」で、管理15項目の準備・手順・反映・困ったときの案内を確認できます。カテゴリ画面からも開けます。項目を選ぶだけでは実行せず、「○○を開く」で実際の画面へ進みます。普段の8項目は `/menu → 使い方` にまとめています。[全機能の見直し](V6.md)。

| カテゴリ | 操作 |
|---|---|
| 予定・卓 | 予定表、卓・キャラシ、日程調整 |
| 入室・音声 | VC設定、音声設定、入室パネル |
| 外観・投稿 | Botのバナー、投稿タグ |
| 運用・管理 | バージョン管理、動作診断、脆弱性診断、チップ管理、設定を確認、ENV・起動設定、Botを再起動 |

設定名が分かる場合は `/admin` の任意項目 **「操作」** から直接開けます。15個の設定はカテゴリ名付きで表示されます。たとえば「外観・投稿 / Botのバナー」「運用・管理 / バージョン管理」を選ぶと、その画面を開きます。省略すると管理メニューを表示します。設定を開くだけでは、更新・再起動・画像の適用・残高調整・パネルの設置は実行しません。

Botの更新は「バージョン管理」から手動で実行します。画像のアップロードは「外観・投稿 → Botのバナー」です。[画像の変更手順](BANNER.md) を参照してください。
管理者権限は操作ごとに確認します。管理画面の有効期限は10分で、期限切れや再起動後は `/admin` から開き直してください。

## 更新前の容量を調べる

更新前の容量は `/admin → バージョン管理 → 更新を確認` で確認できます。コード取得・依存再利用・追加保存量・OSの空きを表示し、取得できない項目は未確認にします。[容量表示の意味](UPDATE_CAPACITY.md)

## 予定を探す・取り出す

`/menu → 予定表`、公開投稿の「カレンダーを開く」、または `/admin → 予定表` で予定表を選び、「検索・取り出し」（管理者は「検索・整理」）から操作します。一覧からの直接検索、`日付:2026/10/17`・`月:2026/10 図書館` の日時条件と予定名・場所・説明の全期間検索、および、表示中の月・日付・週・30日分・検索結果の `.ics` 取り出しに対応します。管理者は予定の詳細から「複製して編集」で同様の予定を追加できます。共有を解除する場合は管理者が「検索・整理 → 投稿を管理 → 投稿 → この投稿の共有を停止」で確認します。予定データは保持し、古い閲覧画面も無効化します。[予定表の操作手順](CALENDAR.md) を参照してください。

## 連休・繰り返し予定を追加する

管理者が `/admin → 予定表` で操作します。複数日の終日予定は日付に `2026/10/30〜2026/11/02` を入力します。定例の予定は詳細の「繰り返して追加」から間隔・件数・全日程を確認して一括保存します。[予定表の操作手順](CALENDAR.md) を参照してください。

## ICSファイルから予定を取り込む

管理者が `/admin → 予定表 → 検索・取り出し → ICSファイルから取り込む` でアップロードし、新規・重複・全日程を確認して保存します。UTF-8・256KiB以内・200予定までです。既存予定は上書きせず、同じ内容の予定を除外します。[対応形式と公開範囲](CALENDAR.md) を確認してください。

## 日程調整を作成・共有する

`/admin → 予定・卓 → 日程調整` で内容を入力・確認して作成します。「回答URLを共有」で回答ページだけを元のチャンネルへ投稿します。作成結果の未確認と共有結果の未確認は別の状態です。[入力・エラー復帰・共有の手順](DENSUKE.md) を参照してください。

## キャラシパネルを設置・復旧する

`/admin → 予定・卓 → 卓・キャラシ` から操作します。設置結果が分からない場合は、同じパネルの「復旧結果を登録」へ **Bot投稿のリンク** を貼り付けて確認できます。メッセージIDも使用できます。投稿を作り直す操作ではありません。PCの控えのZIPは同じ画面から1ファイルずつ取得でき、途中で控えが変わった場合は一式を取り直します。[設置・復旧・控えの保存手順](TRPG.md) を参照してください。

## ENV・起動設定を変更する

`/admin → 運用・管理 → ENV・起動設定` から変更できます。`/admin` の「操作」で「運用・管理 / ENV・起動設定」を選んでも開けます。

| 項目 | 値 |
|---|---|
| バックアップ読み上げ（ASTRAL_BACKUP_TTS） | 0=OFF、1=ON |
| 合成スレッド数（VOICEVOX_BACKUP_THREADS） | 1〜4、既定2 |

項目を選び、値を入力 → 変更内容を確認 → 変更を保存。同じ画面の「Botを再起動」から確認・再起動すると反映します。画面に稼働中と次回起動時の値を表示します。読み上げをONにする前に、Discord Developer PortalでMessage Content Intentを有効にしてください。

保存値は外部の環境変数より優先し、空欄で保存すると外部設定・既定値へ戻します。`.env` の編集は不要です。設定は `data/runtime-env.json` に保存し、GitHubからの更新後も保持します。
トークン・接続先サーバーID・実行パス・任意の環境変数は表示/編集しません。伝助メールの宛先は、従来どおり「日程調整 → 控えメールの宛先」で変更できます。

## Botを再起動する

`/admin → Botを再起動 → 再起動を確認 → 再起動する`。現在の版で再接続し、保存済みの起動設定を反映します。再起動中はdndになり、読み上げ・ゲームなどの進行中は見送ります。起動設定で失敗した場合は直前の設定へ戻して復旧を試みます。

v3.34以前から再起動機能へ切り替える場合は、手動更新後にQuaxly側で一度Restartを実行します。常駐する起動プロセスに変更がある更新でもQuaxly側のRestartが必要です。通常のBot再起動と使い分けてください。[切り替え・復旧の詳細](RESTART.md) を参照してください。

## 途中の操作を再開する

管理メニューや別の機能へ移動した後、**同じチャンネルで同じ機能を開く**と、有効期限内なら続きから操作できます。

| 機能 | 引き継ぐ内容 |
|---|---|
| 予定表 | 選んだ予定表、表示月・日付、表示形式、入力エラー時の下書き |
| 卓・キャラシ | 検索条件、選んだ卓やパネル、入力中の下書き |
| 日程調整 | 入力内容、内容確認、作成済みURL、結果未確認の状態 |
| 投稿タグ | 選んだ投稿、タグの順番、更新結果 |
| Botのバナー | 未適用の候補画像。現在のバナーは再取得して比較 |

最初に開いてから10分間の操作期限は、開き直しても延長されません。期限切れ・Bot再起動後は新しい画面を開きます。下書きと候補画像はメモリ内だけに保持し、再起動後には復元しません。別チャンネルで開く場合は新しい操作になります。

再開しても、伝助の作成・回答URLの共有・画像の適用・投稿は実行しません。予定表の削除や送信の確認は、内容をもう一度選んで確認してください。削除済みの予定や卓を選んでいた場合は、使える一覧へ戻ります。

期限切れや操作失敗の画面には、その機能を開き直すボタンや所属カテゴリへ戻るボタンがあります。閲覧用の予定表は元の投稿の「カレンダーを開く」から開き直してください。管理画面を開くたびに、現在の権限を確認します。

| 旧コマンド | 新しい入口 |
|---|---|
| `/vc` | `/menu` → VCに入る |
| `/game` | `/menu` → ゲーム |
| `/read start` | `/menu` → 読み上げ → このチャンネルで開始 |
| `/read status` | `/menu` → 読み上げ |
| `/read stop` | `/menu` の「操作」で「読み上げを停止」 |
| `/chips` | `/menu` → 自分のチップ |

v3.31への手動更新後、新しい2コマンドの登録成功時に旧コマンドを整理します。保存済みの設定・予定・チップ残高は維持します。既存の入室パネルと各機能のボタンも利用できます。
Discordで古い候補が残るときは、画面を開き直してから `/menu` を選んでください。コマンドが見えない場合は、管理者がサーバー設定の連携サービスから利用権限を確認してください。

## スペック・音声速度を測定する

`/admin → 運用・管理 → 動作診断` でCPU・メモリ割当と直前の停止理由を確認できます。**「速度を測る → 測定を開始」** で固定文の合成とOpus変換を実測します。VCへの音声送信はありません。直近5回の測定履歴・直前の完了結果との比較・非公開JSON取得にも対応します。状態更新・測定中断に対応し、測定中は音声処理・更新・再起動と同時実行しません。[項目の意味と対処](DIAGNOSTICS.md) を参照してください。

## 依存パッケージの脆弱性を確認する

`/admin → 運用・管理 → 脆弱性診断 → 診断を開始`。直接操作の「運用・管理 / 脆弱性診断」や動作診断の操作の選択欄からも開けます。本人だけに結果を表示し、バージョン管理から手動更新へ進めます。[対象・送信内容・制限](SECURITY_SCAN.md)。

## 予定をまとめて整理する（v5.0）

`/admin → 予定表 → 検索・整理 → 整理・復元` で、一括日付移動・編集削除履歴の復元・時間の重なりを確認できます。履歴消去にも確認画面があります。管理ショートカットは15個のまま、2コマンドから開きます。[操作手順](V5.md)。

## v5.1 共通メニューと診断の導線

`/menu` の「目的・説明から機能を探す」で7機能へ、`/admin` の「設定名・目的から直接開く」で全15機能へ直接進めます。既存のカテゴリ・直接コマンドも使えます。開くだけで読み上げ開始・更新・再起動・送信は行いません。動作診断の「対処の手順」、脆弱性診断の対象絞り込み・全件JSON保存も利用できます。[詳しい手順](V5_1.md)。

## チャットでダイス・サイゼロールを振る（v6.6）

`1D100`、`1D4,3D10`、`3D10を振って`、`1d10ふって`、`お風呂の温度は1D100度！！`、`ダメージ 3D10` などの投稿に、カードのリプライで結果と全内訳を返します。`サイゼロール` / `サイゼロールして` なら `(1D3)(1D4)0(1D10)` を連結した番号を返信します（末尾の10は0に変換）。`!サイゼロール` の場合だけ参照表の料理名も表示し、末尾の `!` では料理名を出しません。説明・質問・引用などは見送ります。Message Content Intentが無効な場合はBotをメンションして投稿してください。ON/OFFは `/admin → 運用・管理 → 設定を確認` から切り替えられます。[例と制限](DICE.md)。

## v5.3 使い方と修正導線

`/menu → 使い方 → チャットダイス` を追加。管理者は動作診断で読取範囲とON/OFFを確認できます。予定表の重なり確認では、表示中の予定を直接開き、編集後に重なりを再確認して戻れます。コマンドは引き続き2つです。


## v5.4 操作と表示時点

`/menu` と使い方の画面は、読み上げの有効化状態と、ダイスのON/OFF・通常投稿/メンションの対応範囲を読み取って案内します。設定は変えず、実際の投稿・音声試験も行いません。設定を変えたあとは画面を開き直してください。

自分のチップ・管理者の調整履歴に取得時刻を表示します。残高は画面表示時、履歴は取得時点の内容です。種類やページの切り替えでは履歴を取り直さず、「残高・履歴を更新」（調整履歴では「履歴を更新」）で再取得します。種類を絞って0件なら、その旨と解除・更新の手順を表示します。保持する履歴件数や公開範囲は従来どおりです。


## v5.5 PC・スマホ共通の配置

主要画面は1行3ボタン以内に整理しました。メインの「目的・説明から機能を探す」、管理の設定名・カテゴリ、各機能の「操作を選ぶ」から補助操作を開きます。予定表の追加・検索・複製や読み上げの内訳などもここから選べます。削除・消去・更新・再起動の確定には従来の確認画面を使います。[画面別の操作場所](COMPACT_UI.md) を参照してください。


## v5.6 カレンダー画像の前後の月

月末が土曜日でも翌週を追加して翌月1〜7日を表示します。前後の月の予定は薄字・淡い帯、件数は当月分です。薄字の予定の詳細はその月へ移動してください。操作の選択欄やICSの範囲、ボタン配置は従来どおりです。[予定表の見方](CALENDAR.md)。

### ダイスの文字数・Jev補助判定（v6.6）

通常の文章が30文字以上なら返信せず、AIにも送りません。数字の長い式だけの投稿は例外で、巨大な個数・面数は既存の上限案内を返します。明確な依頼はAPI不要、関連する曖昧な短文だけ設定済みのJevへ送ります。管理者の動作診断でキー設定の有無・モデル・判定状態を確認できます。診断を開くだけではAPIを呼びません。選択欄の「Jevを試す」から固定文の実接続試験を実行できます（有料版を使う場合は課金対象）。[設定と制限](DICE_JEV.md)。


## 高度なチャットダイス（v6.10）

`(2d6+3)*2`（計算）、`4d6kh3` / `4d6kl3`（採用）、`有利で1d20` / `1d20を不利で`、`4d6r1`（一度だけ振り直し）、`1d6!`（爆発）、`5d10cs>=8`（成功数）、`1d100<=70`（比較）を通常の投稿から使えます。式だけはローカルで処理し、曖昧な短文だけJevで返信可否を判断します。全出目を残し、追加抽選の上限時は参考値・判定未確定を表示します。[記法と制限](DICE.md#高度なダイス式v610)。


## 画像工房（v6.11）

`/menu → 画像工房`、または `/menu` の操作「画像工房」から開きます。PNG・JPEGを1枚選び、用途と切り抜き位置を選択して「画像を作成」。本人だけの画面に完成画像を添付します。作成中にメニューへ戻った場合は、完了後に画像工房を開き直すと結果を確認できます。[入力条件・出力・保持期間](IMAGE_WORKSHOP.md)。


## 見やすさの整理（v6.12）

動作診断は「表示・対処を選ぶ」で概要・音声・ダイス/Jev・VC/権限・実行環境へ切り替えます。表示の切り替えは通信・保存を行いません。VC一覧は5件ずつです。メニューの説明を短くし、ゲームとチップ残高をグループ表示、読み上げの消去確認を冒頭へ移しました。[改善前後の見本と詳細](READABILITY.md)。


### v6.13 運用画面の整理

`/admin → 脆弱性診断` の選択欄から対象の絞り込み・勧告詳細・注意点・全件JSON保存へ進めます。バージョン管理の選択欄は概要・容量の内訳・更新手順、ENV・起動設定は稼働中/次回起動の比較です。コマンドは2つのままです。[操作と比較見本](OPERATIONS_UI.md)。


### v6.14 普段使う画面

PC一覧は「検索・表示・控えの操作を選ぶ」、卓・キャラシの入口は「ベース卓・キャラシの操作を選ぶ」へ関連操作をまとめました。4目並べは「コマを置く列を選ぶ」で1手進みます。予定・日程調整・画像・読み方も情報順を整理しました。[操作と比較見本](MEMBER_EXPERIENCE.md)。


### v6.15 案内・測定結果・入力修正

`/menu → 使い方` は機能と案内の種類を選択欄で切り替えます。音声測定の結果は概要・合成/変換・CPU/環境・注意点の4表示。チップ譲渡で入力を間違えても「枚数を入力」から前の入力を修正できます。スラッシュコマンドは2つのままです。[操作と比較](GUIDED_RECOVERY.md)。
