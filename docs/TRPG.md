# キャラシパネルの設置と復旧

管理者が `/admin → 予定・卓 → 卓・キャラシ` から操作します。

## 初めて設置する

1. 「キャラシパネルを設置」を開く。
2. 公開範囲と設置先のテキストチャンネルを選ぶ。
3. 内容を確認し、「この内容で設置」を押す。

Botには設置先の閲覧・メッセージ送信・埋め込み・メッセージ履歴を読む権限が必要です。権限不足の場合は案内に従って直し、同じ画面から確認できます。

秘匿モードのPC名・共有URLは本人と管理者だけが閲覧できます。共有モードではパネルを使えるメンバーへPC名・共有URLを表示します。TXTの控えはどちらも本人と管理者だけが取得できます。設置後に公開範囲は変更しません。

## 投稿結果が確認できない場合

通信が途切れると、実際には投稿ができていても結果が分からないことがあります。Botは同じパネルのIDと未確認状態を保存し、再送せずに復旧操作へ案内します。再起動しても未確認状態は残ります。

1. 設置先でBotのキャラシパネルを探す。
2. 投稿のメニューからリンクをコピーする。
3. 「復旧結果を登録」にリンクを貼り付けて送信する。メッセージIDも使えます。

画面を閉じた場合は、「キャラシパネルを復旧」から同じ設置先・公開範囲のパネルを選びます。初回の設置失敗もこの一覧に残ります。

現在のサーバー・設置先・Bot本人の投稿・対象パネルが一致した場合だけ採用します。登録は既存の投稿へつなぐ操作で、新しい投稿を送りません。入力ミスは「復旧結果を登録」を開き直すと修正できます。

## 設置先に投稿がない場合

送信から1分以上待ち、設置先にBotのパネルがないことを確認してから「設置先にパネルがない」で未確認状態を解除します。解除だけでは投稿しません。対象を選び直し、復旧内容を確認してから実行してください。

送信が明確に拒否された場合や送信前の準備に失敗した場合も、保存済みの同じパネルを選んで復旧できます。登録済みPCと公開範囲は保持します。

## 以前のパネルが使えなくなった場合

「キャラシパネルを復旧」で対象と復旧先を確認して実行します。元の投稿が残っていれば同じ投稿を更新し、失われている場合だけ再設置します。元の投稿が残る状態では別チャンネルへ移しません。

PC登録、TXTの控え、秘匿・共有モードは保持します。古い設置ボタンを押しても新しいパネルを作りません。別のパネルを追加する場合は、新しく「キャラシパネルを設置」を開いて確認してください。
