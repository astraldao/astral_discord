# キャラシパネルの設置と復旧

管理者が `/admin → 予定・卓 → 卓・キャラシ` から操作します。

## 初めて設置する

1. 「キャラシパネルを設置」を開く。
2. 公開範囲と設置先のテキストチャンネルを選ぶ。
3. 内容を確認し、「この内容で設置」を押す。

Botには設置先の閲覧・メッセージ送信・埋め込み・メッセージ履歴を読む権限が必要です。権限不足の場合は案内に従って直し、同じ画面から確認できます。

秘匿モードのPC名・共有URLは本人と管理者だけが閲覧できます。共有モードではパネルを使えるメンバーへPC名・共有URLを表示します。TXTの控えはどちらも本人と管理者だけが取得できます。設置後に公開範囲は変更しません。

## 投稿結果が確認できない場合

通信が途切れると、実際には投稿ができていても結果が分からないことがあります。Botは同じパネルのIDと未確認状態を保存し、再送せずに復旧操作へ案内します。再起動しても未確認状態は残ります。

1. 設置先でBotのキャラシパネルを探す。
2. 投稿のメニューからリンクをコピーする。
3. 「復旧結果を登録」にリンクを貼り付けて送信する。メッセージIDも使えます。

画面を閉じた場合は、「キャラシパネルを復旧」から同じ設置先・公開範囲のパネルを選びます。初回の設置失敗もこの一覧に残ります。

現在のサーバー・設置先・Bot本人の投稿・対象パネルが一致した場合だけ採用します。登録は既存の投稿へつなぐ操作で、新しい投稿を送りません。入力ミスは「復旧結果を登録」を開き直すと修正できます。

## 設置先に投稿がない場合

送信から1分以上待ち、設置先にBotのパネルがないことを確認してから「設置先にパネルがない」で未確認状態を解除します。解除だけでは投稿しません。対象を選び直し、復旧内容を確認してから実行してください。

送信が明確に拒否された場合や送信前の準備に失敗した場合も、保存済みの同じパネルを選んで復旧できます。登録済みPCと公開範囲は保持します。

## 以前のパネルが使えなくなった場合

「キャラシパネルを復旧」で対象と復旧先を確認して実行します。元の投稿が残っていれば同じ投稿を更新し、失われている場合だけ再設置します。元の投稿が残る状態では別チャンネルへ移しません。

PC登録、TXTの控え、秘匿・共有モードは保持します。古い設置ボタンを押しても新しいパネルを作りません。別のパネルを追加する場合は、新しく「キャラシパネルを設置」を開いて確認してください。

## PCの控えをZIPで保存する

パネルのPC一覧で「自分の控えをZIPで保存」を押すと、本人のPCだけを取得できます。管理者には「このパネルの控えをZIPで保存」、管理画面の「PCの控えを確認」には「全PCの控えをZIPで保存」を表示します。共有モードでもTXTは本人と管理者だけが取得できます。

最初のZIPを本人だけの画面に添付します。件数が多い場合は、表示中の「ZIP 1 / 4」のような番号を確認し、次の順序で保存します。

1. 添付のZIPを端末へ保存する。
2. 「次のZIP」を押して次のファイルを取得する。
3. 最後のZIPまで繰り返す。「前のZIP」から戻ることもできます。

ZIPを切り替えると画面の添付が置き換わるため、先に端末へ保存してください。1個のZIPは最大7MiBで、Discordから通知された送信上限が小さい場合はその上限に合わせて分割します。一度に生成・送信するのは1ファイルです。別の取得が進行中の場合は少し待って再操作してください。

同じ管理画面を開き直しても自動送信しません。「このZIPを取得」で表示中のファイルを取得できます。送信エラー後は「このZIPを再取得」から同じ部分を取得できます。

途中で控えが更新・追加・解除された場合は、異なる時点のZIPを混ぜず、取り出し直す案内を表示します。「最新の控えを取得」で最初から取り直し、その一式を保存してください。新しい取り出し直しには10秒間隔の制限があります。本人用の取り出しは最後まで本人だけの範囲を維持し、管理者向けの取り出しは各操作で管理者権限を確認します。

画面の期限は10分です。Bot再起動後は新しく取得してください。TXT本文やZIPを操作画面に保持したり、ZIPをサーバーのディスクへ保存したりはしません。元のPC登録と控えは変更しません。


## v5.5 卓セットの操作配置

詳細の **「確認・編集・その他の操作」** から、参加PCを確認・外す、卓名・伝助を編集、複製、削除確認へ進みます。PC未登録なら確認・外す項目は表示しません。シナリオ・参加PCの追加、固定・進行状態の変更、外部リンクはボタンに残します。選択欄から保存や削除確定は行わず、変更済みの卓に対する古い選択欄は拒否します。[共通の操作配置](COMPACT_UI.md) も参照してください。
