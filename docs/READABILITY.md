# 見やすさの改善（v6.12）

よく見る状態を先に出し、詳しい情報は必要なときに開く配置へ整えました。新しいコマンドや設定は不要です。

| 画面 | 変更点 |
| --- | --- |
| メイン・管理メニュー | 重複した説明を短縮し、次に使う操作を見つけやすくしました。 |
| 動作診断 | 概要を短くし、詳しい結果を既存の選択欄から切り替えられます。 |
| ゲーム選択 | 残高・継続中の状態を先に表示し、無料ゲームとチップを使うゲームを分けました。 |
| チップ残高 | 残高を先に、増減の全内訳を項目ごとに表示します。履歴・ゲーム記録も引き続き開けます。 |
| バックアップ読み上げ | 読む場所・聞く場所・待ち数をまとめ、待機分消去の確認を先頭に出しました。 |

## 診断の詳しい結果を開く

`/admin → 動作診断 → 表示・対処を選ぶ` から切り替えます。

| 表示 | 確認できる内容 |
| --- | --- |
| 概要 | 確認したい項目、機能の状態、Jevの直前の利用モデル、CPU・メモリ |
| 音声・読み上げ | 音声ファイルの確認、起動設定、直前の停止理由 |
| ダイス・Jev | 投稿への対応方法、設定モデル、無料・有料切替、直前の判定状態 |
| VC・権限 | 全設定済みVCの権限。5件ずつ前後のページで確認 |
| 実行環境 | CPU・メモリ、Node、稼働時間、入室予約数 |

表示の切り替えは、表示された確認時刻の結果を使います。切り替えだけでAPI通信や設定保存は行いません。最新の状態は「診断を更新」、合成・変換の実測は「速度を測る」から確認してください。速度測定にはVC接続・再生までの時間は含みません。

「Jevを試す」は説明画面を開いた後、実行ボタンで実際にAPIへ送信します。有料版へ切り替わる条件もそこで確認できます。詳細は[動作診断](DIAGNOSTICS.md)と[Jev](DICE_JEV.md)を参照してください。

## 配置と操作

ゲームとチップのカードは2つのフィールドを使い、PCでは横に比較しやすい配置にしています。スマートフォンの折り返しはDiscordの標準表示に従います。既存の操作を使い、ボタンの行を増やしていません。

ゲームの抽選・精算、チップの全内訳、読み上げの本文50文字＋「以下略」・投稿順の待機・消去確認の対象は維持しています。依存パッケージ、ENV、保存形式の追加はありません。

## 改善前後の見本

[比較用HTML](previews/readability-v6_12.html)には6画面の改善前後と診断の分野別表示を収録しています。架空の固定データと実際の送信データから作ったモックで、Discord実機の表示確認ではありません。リポジトリのルートで次のコマンドから再生成できます。

```sh
node scripts/preview-readability.js > docs/previews/readability-v6_12.html
```

本番への反映は、従来どおり `/admin → バージョン管理` から手動で行います。
