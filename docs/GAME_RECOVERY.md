# ゲームとチップの復帰を改善（v6.16）

予期しないエラーの案内と、管理者のチップ調整を直して続ける操作を整備しました。

## エラーが出たとき

ブラックジャック、カジノ、じゃんけん、4目並べ、チップ譲渡/お手伝い、チップ管理では、SDKや内部処理の生のエラー文を返信へ出さず、状態や履歴を確認する案内を表示します。入力ミス・残高不足・期限切れなど、Bot内で定義した案内は引き続き具体的に表示します。

エラー後にゲームや残高を表示し直す際も、現在の権限・本人・チャンネル・期限を確認します。権限がなくなっている場合は、カード画像・相手・残高などを付けず、戻り先だけを案内します。表示し直す処理自体が失敗した場合も、内部文面を含まない簡単なカードへ切り替えます。

エラー表示だけで抽選・精算・譲渡・保存を再実行しません。調整フォームの返答結果が不明な場合も、自動でフォームを送り直しません。結果が反映済みの場合もあるため、現在の画面や履歴を確認してください。

## 管理者のチップ調整を直す

`/admin → チップ管理` で対象と調整方法を選びます。

1. 入力エラーが出たら「元の画面を確認」を押す。
2. 同じ対象・調整方法を選ぶと、前の枚数と理由を直せる。
3. 改めて確認画面へ進み、現在の残高・変更後の案・理由を確認する。
4. 「この内容で保存」で確定する。

入力は枚数9文字・理由100文字までセッションのメモリ内に保持します。フォームに表示できない制御文字は空白に置き換えますが、元の不正入力をそのまま保存することはありません。対象や調整方法を変えた場合、または明示的に戻った場合は下書きを消去します。

「元の画面を確認」は状態を見る操作です。調整・譲渡・抽選は行いません。本人・元チャンネル・現在の管理者権限・期限・対象メンバーを再確認し、古い復帰ボタンやフォームは拒否します。

## 確認した後に残高が変わった場合

確認時の残高や履歴が変わっていたら、先頭に注意を表示し、保存を無効にします。残高が増減して同じ数に戻っていても、履歴の変更を検出します。ブラックジャックの進行中も調整できません。

「変更せず戻る」で最新の残高から入力し直してください。調整する枚数を自動で変更したり、新しい残高へ自動で適用したりはしません。古いボタンから直接保存しようとしても、台帳側で再確認します。

保存に失敗した場合は調整案を保持して確認できます。保存後の返信だけが失敗した場合は、元の画面で反映済みの残高を確認できます。同じ調整を二重に適用することはありません。
