# 読みやすい案内と入力修正（v6.15）

長い使い方と音声測定の結果を表示別に分け、チップ譲渡の入力を修正して続けられるようにしました。

## 使い方を目的別に読む

`/menu → 使い方` で機能を選び、次の選択欄で切り替えます。

| 表示 | 内容 |
| --- | --- |
| 手順 | 普段の操作手順 |
| 準備・反映・終了 | 使う前に必要なこと、いつ反映されるか、終了の条件 |
| うまく動かないとき | 動かない場合の確認先 |
| 高度なダイス | チャットダイスの計算・採用・振り直し・成功数など |
| サイゼロール | サイゼ用の式と、`!` を付けたときだけ料理名を表示する条件 |

下の2つはチャットダイスにだけ表示します。機能を開く操作は従来のボタンです。案内の切り替えで機能の起動・設定保存・AI照会は行いません。

ダイスは通常の文章が30文字未満、式だけの投稿は例外という条件や、文脈判断・全内訳・サイゼだけの末尾10→0も維持します。読み上げの未有効、ダイスのOFFやメンションが必要な状態は引き続き表示します。

## 音声の測定結果を読む

`/admin → 動作診断 → 速度を測る` の結果を、選択欄で切り替えられます。

| 表示 | 内容 |
| --- | --- |
| 概要 | 先頭音声・合成時間・実時間比・停止理由・中断元 |
| 合成・変換 | モデル準備、音声の長さと分割待ち、Opus初期化/変換、合成方式 |
| CPU・実行環境 | CPU/メモリ、実行スレッドと設定上限、プロトコル、CPU実行時間・制限 |
| 測定範囲・注意点 | 測定対象外、CPUと経過時間の違い、メモリの読み方、履歴の保持条件 |

表示切り替えは再測定・中断・外部AIへの照会を行いません。現在の権限確認と画面更新は行います。「状態を更新」は従来と同じ位置です。測定中は進行中の情報だけを表示し、中断確認は先頭に出します。前回の測定結果を現在の進捗へ混ぜません。

実時間比が1以上なら連続投稿で待ちが増える可能性を注意色で表示します。ホストの混雑や実際にVCで聞こえるまでの速度を、その数値から断定しません。音声合成・変換・計測方法・待ち時間の上限は変更していません。

測定結果の表示にも既存の履歴と同じ許可項目・数値範囲の検証を適用します。未知の値は未計測/未確認とし、ネイティブ処理の生メッセージ・任意のモデル情報・パス等は表示しません。

## チップの枚数を直して続ける

`/menu → ゲーム → チップを渡す` で、相手・枚数・最終確認の順に進みます。

整数でない値や残高を超えた枚数を入力した場合も、同じ相手への入力を最大9文字まで保持します。「枚数を入力」を開き直すと前の入力を直せます。同じ相手の再選択や同じチャンネルでの再開でも保持し、相手を変えた場合や新しい譲渡では消去します。

入力を直しただけではチップは移動しません。有効な枚数で改めて確認画面へ進み、「この相手に渡す」で確定します。古い入力フォームは無効になり、本人・元チャンネル・期限・現在権限と、台帳に書く直前の確認は維持します。入力はセッションのメモリ内だけで、保存形式は変わりません。
