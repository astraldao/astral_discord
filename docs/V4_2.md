# v4.2 の使い方

予定表に週間・30日分の一覧を追加し、メニューに使い方と最近開いた機能をまとめました。入口は `/menu` と `/admin` の2つです。

## 今週・次の予定を見る

`/menu → 予定表` で共有予定表を選び、**「表示を切り替える」** を使います。管理者の予定表にも同じ切り替えがあります。

| 表示 | 操作・範囲 |
|---|---|
| 月カレンダー | 従来の画像で月全体を見る。「前の月／今月／次の月」「月を指定」で移動 |
| 月の一覧 | 月全体を日付順の文字で見る |
| 週間 | 日曜〜土曜を文字で見る。「前の週／今週／次の週」で移動 |
| 今日から30日 | 日本時間の今日から29日後まで。「今日から更新」で開始日を更新 |

週間は選択中の日を含む週から開きます。日付未選択なら、今月では今日、別の月では1日を含む週です。30日分は今日の予定を時刻にかかわらず含みます。対応範囲は2000〜2099年で、境界の週や2099年末は範囲を短くします。

複数日の予定と前日から翌日に続く時刻付き予定は、期間に重なれば1件として表示します。「期間前から続く予定」と元の日時を確認できます。午前0時に終了した予定は翌日の分に含めません。月・日別表示の従来の集計は維持します。

予定の詳細から戻っても表示範囲とページを維持します。「今日の予定」「日付を選ぶ」で日別表示へ移り、月表示の選択で月全体へ戻れます。

## 検索・取り出し・管理

一覧の **「検索・取り出し」**（管理者は **「検索・取り出し・管理」**）から操作します。

検索は選んだ予定表の全期間が対象で、検索解除後は元の月・日・週・30日分へ戻ります。ICSには表示範囲の全ページ分を含め、期間前から続く予定も元の開始日・終了日のまま取り出します。ほかの予定表を混ぜません。

管理者の共有・投稿管理・名前変更・ICS取り込みは、この画面にまとめました。「予定を追加」は一覧からも押せます。チャンネルへの共有は引き続き月カレンダーで、送信先と内容を確認してから送ります。

詳しい形式・公開範囲は [予定表の手順](CALENDAR.md) を参照してください。

## 操作を探す・戻る

`/menu → 使い方` で6項目の手順を選べます。**「この機能を開く」** に相当する各ボタンで、その操作画面へ進めます。

メニューには同じチャンネルで最近開いた最大3機能も表示します。本人だけの履歴で、最後にメニューから機能を開いてから10分間、メモリ内に保持します。Bot再起動で消え、ユーザーとチャンネルの組み合わせを全体で最大200組に制限します。メニューや使い方を表示するだけでは期限を延長しません。

履歴から読み上げを開いても、自動開始しません。停止などの操作を履歴から再実行せず、常に現在の権限と各機能の確認を通します。

## 手動更新

`/admin → バージョン管理 → 更新を確認` で **v4.2.0** を確認し、更新内容を見て適用してください。新しいENV・依存パッケージ・データ移行は不要です。

予定表・メニューの想定外の例外は、内部パスやリクエスト詳細を表示せず、固定の復旧案内に置き換えました。日付などの入力ミスには従来の具体的な案内を残しています。

検証は模擬Discordと一時ファイルで実施しました。実機の表示・音声は手動更新後に確認してください。
