# v6.0 全機能の操作と案内を整理

普段使いは `/menu`、管理は `/admin` のままです。準備・操作・反映の説明を揃え、混雑・空表示・ページ移動で迷いやすい箇所を改善しました。

## 新しい案内

- **`/menu → 使い方`**：普段使いの7項目に「使う前に」「手順」「反映・終了」「うまく動かないとき」を表示します。
- **`/admin → 設定名・目的から直接開く → 全機能の操作ガイド`**：管理15項目の準備・手順・反映と保存・困ったときの案内を表示します。カテゴリ画面からも開けます。
- ガイドで機能を選び、「○○を開く」で実際の画面へ、「詳しい手順を読む」で文書へ進みます。

ガイドの選択だけでは、設定保存・画像適用・公開投稿・外部作成・脆弱性照会・更新・再起動は実行しません。診断を実際に開く場合は状態を確認します。ガイドも本人・管理者権限・チャンネル・有効期限を確認します。

## 全機能の見直し

| 機能 | 改善・確認した内容 |
|---|---|
| VC入室・設定 | 準備と移動の流れを統一。ロビー・行き先・待機・直接入室の変更を前後の値で表示 |
| 音声告知・辞書 | 告知とチャット読み上げを区別。辞書の正規化後の表記と読みを比較 |
| バックアップ読み上げ | 待機6件で混雑、8件で満杯を案内。再開や待機分消去の場所を明示 |
| 本人の読み方 | 準備・次の告知への反映・解除後の自動読みを案内 |
| 全10ゲーム | 無料/最低10枚を明記。10枚未満なら無料3種類を先に表示 |
| チップ・譲渡・管理 | 履歴や調整履歴のページ移動を含め、1行3ボタン以内に整理 |
| チャットダイス | 無料の投稿返信と、ゲーム内のチップを賭けるダイスを区別 |
| 予定表・検索・ICS | 一覧に「表示N件 / 全M件」を表示。ページ内と表示条件全体を区別 |
| 卓・キャラシ・PCの控え | 準備・保存と公開・復旧をガイド化。秘匿/共有とバックアップを維持 |
| 日程調整 | 空行を除く候補数を表示。確定予定を扱う予定表との役割を明示 |
| 入室パネル | 必要なVC設定・設置先・設置済み投稿の更新を案内 |
| バナー | 画像サイズ・プレビュー・Bot全体への反映・結果確認を案内 |
| 投稿タグ | タグなしの前提と再選択を案内。操作できない保存ボタンを並べない |
| バージョン管理 | 見送ったときに進行中の処理を確認する案内と、普段のメニューへの出口を追加 |
| 動作診断・音声速度 | 状態確認と実測を区別し、固定文を使いVCへ送らないことを案内 |
| 脆弱性診断 | 対象範囲・操作時の照会・自動修正しないことを案内 |
| 設定一覧・ダイス設定 | 変更前後と、保存後にも変更内容を表示 |
| ENV・起動設定 | 稼働中/次回起動と、保存だけでは反映しないことを案内 |
| 再起動 | 起動設定の変更あり/なしを明示。見送り時は普段のメニューへ進める |

既存のエンジンやデータ形式を一律に作り直した更新ではありません。各機能の役割を保ち、共通案内と具体的な操作上の問題を修正しています。日程調整・確定予定・卓とPCの管理を重複する新機能へ分け直していません。

## 変更前後と操作の境界

従来から確認が必要な設定は、変更前後を確認して保存します。通常の即時保存は維持し、不要な確認操作を増やしていません。保存後にも何を変えたか表示します。ほかの管理者による変更や、保存時の権限・操作画面の変更も引き続き検証します。

スラッシュコマンドは2つ、直接開く管理操作は15個のままです。ガイドは選択欄の補助項目です。ゲームのルール・精算、読み上げの本文50文字＋以下略・FIFO・待機8件、共有範囲・ICS・秘密情報の扱い、結果不明時の重複作成防止を維持します。トークンや編集可能なENV項目は追加していません。

## 検証と反映

ガイドの全項目と文書リンク、選択だけでは処理を走らせないこと、権限取消・他ユーザー・別チャンネル・期限切れ・不正な値の拒否を検証します。設定の正規化・非変更性、ゲームの選択肢10個と無料優先、履歴の行幅、待機本文の非表示、タグなし、候補数・予定件数、見送り後の出口も確認します。

PC/スマホは同じDiscordネイティブの選択欄とボタンを使います。本番のDiscord端末表示は未確認です。実機ではガイド→機能、読み上げ、ゲーム再開、履歴のページ送り、予定の詳細と戻る、更新前の容量確認を確認してください。

利用手順は [コマンド早見表](COMMANDS.md)、[予定表](CALENDAR.md)、[読み上げ](BACKUP_VOICE.md)、[卓・PC](TRPG.md)、[日程調整](DENSUKE.md)、[バナー](BANNER.md)、[診断](DIAGNOSTICS.md)、[脆弱性診断](SECURITY_SCAN.md)、[容量](UPDATE_CAPACITY.md)、[再起動](RESTART.md)を参照してください。

反映は **`/admin → バージョン管理`** から手動更新します。自動更新は追加していません。
