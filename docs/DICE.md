# チャットダイス（v5.2）

チャンネルにダイスの依頼を投稿すると、元メッセージへのリプライで結果を返します。複数個なら合計と内訳を表示します。チップや課金は使いません。

| 投稿例 | 動作 |
|---|---|
| `1D100` | 100面ダイスを1個 |
| `1D4,3D10` | 4面1個、10面3個を別々に集計 |
| `判定1D100` / `ダメージ 3D10` | 判定やダメージの短い宣言として実行 |
| `3D10を振って` / `1D100振ってくれる？` / `roll 3d10` | 明示的な依頼として実行 |
| `2D6+3` | 2個の合計に3を加算 |
| `1D100って何？` / `1D100を振らない` | 反応しない |
| コード、引用、URL、ネタバレ内の表記 | 対象外 |

大文字・小文字・全角数字に対応します。文脈は保守的なルールで判断し、説明・説明を求める質問・過去の話・否定・引用符を含む文章や、曖昧な長文には反応しません。すべての自然文を理解するAI機能ではありません。反応しない場合は、ダイス表記だけの新しい投稿で依頼してください。編集しても再実行しません。

## 通常の投稿で反応させる

Discord Developer Portal → Bot → Privileged Gateway Intents → **Message Content Intent** を有効にし、Botを再起動してください。起動時にDiscordのアプリ情報から有効化を確認します。既存のバックアップ読み上げで有効になっている場合は、その設定を使います。

未有効・確認できない場合でも、Botをメンションした `@Bot 1D100` のような投稿では利用できます。特権Intentを無条件に追加してBot全体のログインを失敗させることは避けます。Portal側の変更は再起動後に反映されます。

Botには対象チャンネルの閲覧・メッセージ履歴・送信、スレッドならスレッド送信権限が必要です。アーカイブ・ロック済みのスレッドには返信しません。

## ON/OFF

既定はONです。管理者が `/admin → 運用・管理 → 設定を確認 → ダイス返信をOFF/ON` から変更できます。保存後に反映し、この切り替え自体に再起動は不要です。待機中のVC入室予約がある場合は既存の確認画面が表示されます。

## 制限とプライバシー

1投稿最大5式、各式1〜100個・面数2〜100万、合計200個、補正±100万までです。内訳は各式20個まで表示し、合計は全個数を計算します。1ユーザー2秒間隔・全体200ms間隔・同時4返信まで。混雑時は反応を見送ります。

投稿本文を保存・ログ出力したり外部AIへ送信したりしません。抽選には暗号学的乱数を使いますが、第三者が検証できる抽選証明ではありません。個人情報やメンションは結果に引用せず、通知メンションも付けません。返信の結果が確認できない場合の自動再送は行いません。

更新は `/admin → バージョン管理` から通常どおり手動で行います。新しい依存やENV値の追加はありません。
